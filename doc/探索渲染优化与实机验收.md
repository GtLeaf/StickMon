# 探索渲染优化与实机验收

## 2026-11-01：复用原地图缓存降低夜间着色成本

针对上一批古瀑谷夜间约53ms的绘制时间，本批将固定夜色色调并入既有缓存。
不改变美术、玩法、存档、传屏并行配置或刷新节奏，切图与存档停顿继续延期。

### 实现与边界

原生图块按2倍绘制，缓存中的相邻行重复。本批在同一块832×624 RGB565世界
缓存内，用偶数行保存夜色、奇数行保存原色；内存大小不增加，没有新增整图缓存。
视口按图块合并复制区间，静态区域直接复制夜色，动画、动态草丛、精灵/阴影、
头目及拾取物覆盖区域复制原色。后者沿用原图层合成顺序，最后统一着色一次，
避免阴影先后次序或重叠区域重复着色产生像素差异。额外临时状态只有192个图块标记。

缓存构建前检查相邻行确实相同，不满足时保留原色缓存并回退，避免未来原生
细节/缺失素材回退图形被误压缩。缓存键区分原色、夜色行对及不可压缩回退，
保留地图种子、区域、字节序。黄昏/黎明继续原始着色，不因每分钟色调变化
反复重建；进入/离开固定夜色时有一次缓存重建，不属于稳定滚动样本。
这会增加首次夜间缓存准备成本，本批没有优化切图停顿。

首次尝试仅保存已着色静态底图、重画精灵覆盖区，青草径有效，但古瀑谷
动态区域较多，约53.0→53.3ms未改善；已替换为上述原色/夜色同行分存实现。

## 2026-10-31：第二批，减少重复绘制工作与 V2 并行传屏

### 实现

- 原生半透明圆角标题每次只建立一组 RGB 混色表，替代每行重复建立；保持
  圆角覆盖、颜色舍入、裁剪、字节序和缩放回退。
- V2 增加一块 368×448 RGB565 显示帧缓冲（329,728 B PSRAM）和 core 1
  传屏任务（3072 B 栈、两个单项队列）。UI 绘制下一帧时传屏任务读取上一帧；
  同时最多一个待完成帧，原有两个 DMA 分条缓冲不增加。
- 帧缓冲交换时只补齐上次脏区中本帧不会覆盖的像素；切场景、淡入淡出、锁屏
  快照前等待传屏完成。分配失败回退同步；普通传输错误排空后回退完整重绘。
  DMA 超时不复用所有权未知的内存，尝试保存后停止显示循环，等待设备重启。
- worker 不访问游戏状态、资源或绘制器；性能统计使用实际传屏完成时间。
  debug 可用 `diag pipeline 0/1` 对照，默认启用；V1 仍使用同步传屏。

另测过用内部 RAM 分块中转夜间着色；真实 V2 上原实现约16.0ms，中转方案
约24.4ms，因此已撤回，不纳入正式固件。桌面速度不能代替 PSRAM 实测。

## 2026-10-14：位置刷新与局部矩形刷新

2026-10-14，微雪 AMOLED V2；V1 复用同一套应用和 UI。本轮实现位置刷新与走路动画解耦、静止镜头下的局部矩形刷新。

## 实现

- `updateExploreRoute` 每次移动更新都会请求位置刷新，走路精灵图仍按 90ms 换帧；不再等待换帧才显示新的位置。暂停探索仍不持续刷新。
- 动态刷新范围取上次绘制和当前精灵范围的并集，包含领队、跟随精灵、浮空偏移和阴影；按实际帧尺寸计算，替代原来精灵上下各 120 像素的全宽条带。
- 应用合并矩形脏区；普通按行刷新会扩展为全宽。页面裁剪、世界地图缓存的背景恢复、草丛遮挡和板级传屏均使用同一个横向范围。V1/V2 使用已有矩形传屏路径，锁屏原有按行强制刷新保留。
- 镜头变化时刷新全部地图区域 `0..344`；场景切换和淡入淡出继续完整刷新。每 10 步回复 HP 后明确刷新底部状态区。

## 验证

Debug native 40 项测试通过，新增逐像素对比覆盖 20ms 内位置刷新但未换动画帧、四方向、不同体型和浮空精灵、跟随精灵停止、阴影、草丛遮挡、镜头滚动及暂停。局部刷新与同一时刻的完整画面一致，脏区外像素未被修改。探索页面 18 项、探索步进 14 项、锁屏 6 项、渲染调度 2 项检查通过；V1/V2 Claw Debug 构建通过。

V2 刷入应用和当前资源包，均通过设备哈希校验；分区表与构建一致，启动槽为 ota_0。刷入前已备份配置与存档，没有覆盖 NVS。通过 `diag explore 0` 走正常出门、自动战斗、拾取和回房流程，进行了两轮实机探索。
