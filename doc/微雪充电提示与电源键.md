# 微雪充电提示与电源键

适用：AMOLED 1.8 V1 / V2。2026-11-03 实现；V2 已刷入并验证启动，真实充电提示与断电行为待用户验收，V1 尚未刷机。

- 房间顶部电池在实际充电时叠加黄色闪电，停止充电后移除；接上 USB 但未充电不会误报。沿用电量的 5 秒采样周期，唤醒立即更新，仅刷新房间顶部区域。
- 开机按键时间设为 AXP2101 支持的 128ms，日常操作为短按一次 PWR。
- 正常运行时，PWR 短按先取消当前触摸并保存现有存档与孵化进度，保存成功才发送 PMU 关机命令。保存失败或处于写保护时保留运行并提示保存失败。
- 启动阶段清除旧按键事件，并要求新按下与短按事件配对，防止开机键尚未松开导致再次关机。事件由 PMU 锁存，锁屏等待不会漏掉点击。
- 硬件长按恢复方式保留。BOOT 的下载模式功能保持原样。

实现复用 `firmware/common/Axp2101Battery.*` 和 `AmoledPowerButton.h`，两块微雪板共用按键语义；平台充电接口默认返回 false，其他硬件不虚构充电状态。

寄存器依据：[XPowers AXP2101 实现](https://github.com/lewisxhe/XPowersLib/blob/master/src/XPowersAXP2101.hpp)、[AXP2101 参数定义](https://github.com/lewisxhe/XPowersLib/blob/master/src/XPowersParams.hpp)。充电状态取 REG01[7:5]，开机时间只修改 REG27[1:0]，仅消费 REG49 的按下/短按事件；关机通过 REG10[0]。不改充电电流、电压、保护阈值或输出电压。

验证与导出画面位于 `.stick-local/artifacts/amoled-power-charge-20261103/`。主机检查覆盖充电/非充电/无电池/读取失败、充电状态独立刷新、保存失败与成功重载、开机按键抑制、跨轮询事件和时间回绕。实机仍需确认插拔充电线后的图标、PWR 单击关机/开机，以及 USB 连接时的实际断电行为。
