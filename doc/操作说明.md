# StickMon 操作说明

更新日期：2026-08-26

## 1. 按键

- `A`：屏幕底部按键。
- `B`：机身侧面按键。
- 短按：执行当前操作。
- 长按：触发当前场景的快捷操作。

### 1.1 AMOLED V1 当前操作

- 点击精灵：摸摸精灵；心情、亲密度和每日次数写入共享存档。
- 点击碗：将当前选中的真实库存食物放入碗中；库存和碗状态写入共享存档。
- 点击主界面底部左侧的菜单按钮：打开主菜单；旁边的锁按钮关闭屏幕。
- 主界面底部右侧按队伍顺序显示精灵状态：每只精灵一行，左侧饥饿图标会随
  饥饿值减少，右侧为 HP 条；支持同时显示两只正式队伍精灵，访客不占 HUD。
- 主菜单顺序与 StickS3 一致：`EXPLORE / TEAM / ROOM / BAG / SHOP /
  COMPUTER / SETTINGS / COMM / BACK`，并使用同一组图标。
- 在主菜单中上下拖拽：滚动菜单；点击左上角返回按钮回到进入菜单前的页面，
  点击 `BACK` 返回主界面。
- 点击主菜单中的 `EXPLORE`：进入探索区域列表。
- 在探索区域列表中上下拖拽：滚动区域；点击已解锁区域可选中，锁定区域不能
  选择。再次点击已选区域进入路线；首个区域默认已选中，因此可直接点击进入。
  左上角返回主菜单，右上角打开菜单，再返回时会回到探索区域列表。
- 在探索路线中点击地图：开始或暂停自动行走；点击右上角菜单进入独立的探索
  菜单，路线会停在当前位置。菜单依次为 `TEAM / BAG / END / BACK`，图标和
  语义顺序由 StickS3 与 AMOLED 共用；点击左上角返回或 `BACK` 从原位置继续，
  点击 `END` 立即结束路线并返回区域列表。`BAG` 打开与主菜单相同的背包，
  `TEAM` 打开共享队伍页；从子页面返回后仍停留在探索菜单且路线保持暂停。
- 点击主菜单或探索菜单的 `TEAM`：查看最多两名队伍成员的精灵图、等级、HP、
  饥饿值和异常状态。点击当前队首只显示状态提示；点击第二名正式成员并确认后
  可切换队首，队伍顺序、主界面精灵和探索精灵同步更新并立即保存。访客不能
  在此切为队首。
- 点击主菜单的 `BAG`：进入可拖拽背包列表，只显示当前持有物品。点击回复药、
  状态药或复活药后确认即可使用，成功后立即保存；普通回复药作用于队伍首位，
  复活药优先选择首个昏厥成员。进化石会进入成长流程，心之鳞片会进入招式回忆
  页面；金珠、大珍珠和星星碎片也已纳入背包和商店逻辑。
- 点击主菜单的 `SHOP`：分类页左侧选择 `DAILY / EXPLORE / SELL / BACK`，右侧
  预览对应物品图标。进入分类后，在左侧图标列上下拖拽并点击图标选择商品，右侧
  显示名称、价格、持有数和说明；点击 `BUY` 或 `SELL` 后二次确认。商品沿用
  StickS3 的价格、探索解锁条件、99 个堆叠上限和每日糖果限制，成功后金币与库存
  立即保存。
- 点击主菜单的 `ROOM`：进入房间功能页；点击 `SHOWER` 进入洗澡。先选择一种
  持有的肥皂，然后按住屏幕底部的肥皂并拖到精灵身上来回擦拭；起泡完成后，
  点击 `BRUSH`，再按住刷子在精灵身上来回拖动。工具静止或移出精灵身体区域
  不增加进度。两步完成后点击 `RINSE` 自动冲洗，完成后结算共享照护经验与心情。
  肥皂在选择后立即消耗并保存；冲洗前退出会要求确认，避免误操作丢失进度。
- 点击 `ROOM` 中的 `FOOD`：浏览七种房间食物、库存和当前选中项。返回主界面后
  点击碗，会把选中的有库存食物放入碗中；食物选择和碗状态使用共享存档。
- 点击主菜单的 `COMPUTER`：`STATUS` 查看当前正式队伍的等级、HP 和饥饿值；
  `STORAGE` 查看仓库精灵的名称、等级和 HP。仓库页支持上下拖拽和惯性滚动，
  左上角返回按钮逐层返回。当前 AMOLED 电脑页为只读浏览，不改变队伍或仓库。
- 点击主菜单的 `SETTINGS`：点击 `BRIGHTNESS`、`VOLUME`、`GAME SPEED`、
  `POWER SAVE`、`VOICE CALL` 循环修改对应设置，修改后立即保存；点击 `BACK`
  返回主菜单。
- 点击主菜单的 `COMM`：点击 `HOST` 开放访问房间，或点击 `SEARCH` 搜索附近房间；
  搜索到房间后点击 `JOIN` 发起加入。主机收到请求后点击 `ACCEPT` 或 `DECLINE`；
  连接后显示对方精灵和访问倒计时，可点击 `END` 召回访问。连接超时、拒绝和主动
  结束都会进入结果页，点击 `BACK` 返回主菜单。通信使用 ESP-NOW，不需要路由器。
- 探索路线行走到每一步后，会按共享遭遇和探索规则随机触发拾取或遭遇。路线终点
  会按共享 Boss 保底和特殊遭遇规则处理普通 Boss、首次 Snorlax/Latias/Latios、
  游荡 Latias/Latios 及 Mew 事件。战斗支持普通/特殊/蓄力招式、双精灵切换、
  背包治疗和逃跑；胜利后结算经验、金币、区域进度和 Boss 保底状态，失败后回
  房间并保留昏厥状态。
- 在探索路线中点击左上角返回会弹出 `STAY / EXIT` 确认；到达终点后点击地图
  返回区域列表。
- 点击主界面底部左侧的锁：关闭屏幕；再次触摸屏幕唤醒。
- 主界面的精灵会自主移动；饱腹度低于目标值且碗中有食物时，会走到碗边自动进食。
- 顶部时间是存档中的游戏时间，会按照设置的 1x/2x/4x/8x 倍率推进。
- 当前 `EXPLORE`、`TEAM`、`ROOM / FOOD / SHOWER`、`BAG`、`SHOP`、
  `COMPUTER`、`SETTINGS`、`COMM` 和 `BACK` 已接入竖屏流程。探索拾取、随机遭遇、Boss
  与特殊遭遇、普通/特殊/蓄力战斗、双精灵切换、奖励结算以及升级/进化/招式学习
  页面也已接入。捕获/结交交互、路线阻挡/谜题、战斗动画和命中音效也已接入；
  通信页面已接入访问会话、倒计时、心跳、召回和失败状态，但还没有完成两台实机
  联调。

## 2. 房间

- 短按 `A`：和队伍首位精灵互动。
- 短按 `B`：将当前选择的食物放进碗里。
- 长按 `A`：打开主菜单。
- 长按 `B`：进入深度休眠。

## 3. 菜单

- 短按 `A`：确认或进入当前选项。
- 短按 `B`：切换选项。
- 长按 `B`：返回上一层。
- 长按 `A`：直接返回主界面。

## 4. 探索与战斗

### 4.1 选择区域

- 短按 `B`：切换探索区域或“返回”。
- 短按 `A`：前往当前区域，或执行“返回”。

### 4.2 探索途中

- 短按 `A`：开始前进。
- 短按 `B`：打开探索菜单。
- 探索菜单中短按 `B` 切换选项，短按 `A` 确认。

### 4.3 战斗

- 短按 `B`：在“战斗、背包、替换、逃避”之间切换。
- 短按 `A`：确认当前行动。
- 进入背包或队伍等子页面后，长按 `B` 返回。

## 5. 其他操作

### 5.1 弹窗

- 短按 `B`：切换选项。
- 短按 `A`：确认。

### 5.2 洗澡

StickS3：

- 短按 `B`：切换工具。
- 短按 `A`：使用当前工具。
- 使用肥皂或刷子时，倾斜设备进行操作。
- 长按 `B`：退出当前工具或返回。

AMOLED V1/V2：

- 点击 `SOAP` 并选择肥皂，按住肥皂拖到精灵身上来回擦拭。
- 起泡完成后点击 `BRUSH`，按住刷子在精灵身上来回拖动。
- 点击 `RINSE` 自动冲洗；点击 `EXIT` 或左上角返回可退出。
- AMOLED 洗澡不使用体感；只有工具在精灵身体区域内连续移动时才增加进度。

### 5.3 初次孵化

- 短按 `A`：擦一擦蛋。
- 短按 `B`：戳一戳蛋。
- 长按 `A`：打开主菜单。
- 右上角显示剩余孵化时间。

### 5.4 省电与唤醒

- 进入省电模式后，任意按键操作都会唤醒设备并重新开始省电计时。
- 房间中长按 `B` 可进入深度休眠。

## 6. 设置中的操作说明

进入“主菜单 > 设置 > 操作说明”后：

- 短按 `B`：切换到下一页，第六页后回到第一页。
- 长按 `B`：返回设置列表。
- 前五页短按 `A` 不执行操作。
- 第六页短按 `A`：清空已完成的新手引导进度，并返回主界面重新播放引导。

设备内共展示以下六页：

1. 按键说明
2. 房间操作
3. 菜单操作
4. 探索操作
5. 其他操作
6. 重新引导

## 7. 新手引导顺序

新手引导不会锁定操作，只在对应动作成功后记录完成状态：

1. 房间中按 `B` 将食物放进碗里。
2. 房间中按 `A` 和精灵互动。
3. 房间中长按 `A` 打开主菜单。
4. 主菜单中按 `B` 切换项目。
5. 子菜单中长按 `B` 返回。
6. 探索途中按 `A` 开始前进。
7. 探索途中按 `B` 打开探索菜单。
8. 首次战斗中按 `B` 选择行动，按 `A` 确认。
