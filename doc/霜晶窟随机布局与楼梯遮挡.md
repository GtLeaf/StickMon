# 霜晶窟随机布局与楼梯遮挡

更新日期：2026-10-24。按用户批准的原素材预览接入，未刷机，待实机观感验收。

## 地图

共享地图算法版本为 22。保留 A 连续洞室、B 分支侧室、C 冰面穿越、D 双侧梯室
四类布局，每类 96 组，共 384 组经过验证的几何配方。运行时按种子选择，按条件
水平镜像，再使用原有图块铺设墙、冰面、雪路和装饰。配方只保存几何与路线控制点，
不是整图位图；禁止垂直翻转楼梯。Python 与 C++ 使用同一配方表和随机流程。

入口、两条支路出口均为洞内干燥落脚点。第一条出口为向下梯，第二条为向上梯，
保持原有按支路切层规则；取消边界上的亮色裂缝出口。保留冰面直行、干地转弯、
干地放置事件和出口的约束，避免围绕中央封闭岩岛行走。

`tools/frost_cave_layouts.py --check` 校验生成的 `ExploreFrostLayouts.h`；不修改资源包。

## 原素材及遮挡

向下梯使用已收录的 Caves 原素材 4747。向上梯使用两格原素材 4772/4773，
上格在上层、下格在装饰层，始终正向摆放；未新增或绘制美术素材。

两格向上梯共用下格中心作为深度基准。角色在梯后时两格都按深度恢复，在梯口及
前方时角色盖住两格，避免上格无条件盖住大体型角色头部。横屏与 AMOLED 共用
`ExploreTileSemantics` 判断，AMOLED 飞行角色也使用楼梯本身的深度语义。

洞内楼梯的最终离场及提前返回保持队长、同行者各自位置，再完成原过场；不沿
旧边界出口方向穿过洞壁。户外地图保留走出地图边界的离场动作。
