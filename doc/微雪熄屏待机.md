# 微雪熄屏待机

2026-11-04，AMOLED V1/V2 共用应用逻辑，板级显示操作各自接入。

- PWR 短按保存当前状态并熄屏，再次短按恢复完整画面，不重启、不重新加载存档或精灵资源。
- 使用面板驱动的 display-off/display-on 指令；不把黑色帧或亮度为零当作面板关闭。现有 CO5300/SH8601 驱动未提供 sleep 回调，因此不宣称面板已进入控制器深睡。
- 熄屏期间不绘制、不传输帧。后台逻辑每 1000ms 更新一次，PMU 按键事件每 250ms 检查一次；触摸只用于清理中断，不能唤醒显示或操作页面。
- 房间继续使用共享照料、进食、回血、经验和存档流程；移动按 100ms 子步追齐，允许 1 秒调度的正常抖动。菜单、探索、战斗等交互场景保留页面并停止交互推进，继续结算原有时间/照料规则。
- 孵化倒计时继续，IMU 在熄屏时关闭，恢复孵化页后按原规则启用。精灵完成孵化后仍保持熄屏。
- 熄屏时暂停音乐、停止叫声和所有输出、关闭录音，并拒绝新的播放/录音请求。保存的音量、亮度不改变；恢复前在关闭显示的状态下完整更新 GRAM，再点亮面板。
- 原呼吸环锁屏继续保留。从呼吸环锁屏进入熄屏后，PWR 唤醒恢复完整页面。
- 保存失败或存档受保护时不进入待机，显示原保存失败提示。面板切换失败时保留可重试状态。硬件长按电源行为及 BOOT 功能不改。

主机验证包含实际应用模拟待机 1 小时：进食经验、回血、跨日、保存重载、黑屏触摸屏蔽、禁止绘制、菜单保持、孵化倒计时及 IMU 关闭；另覆盖保存失败、调度时钟回绕与触摸事件频繁唤醒时的限频。V1/V2 Lite Debug 构建及原锁屏、显示管线、PMU、架构检查通过。

V2 Debug 可通过 `diag standby` 复用 PWR 的同一切换分支，日志报告实际恢复耗时。串口命令只用于功能验证，不代表按键实测或电池侧电流测量。USB 连接时仍由现有调试保护锁阻止自动浅睡，实际耗电须在电池供电下测量。
