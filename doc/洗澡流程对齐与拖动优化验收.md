# 洗澡流程对齐与拖动优化验收

日期：2026-10-14。

## 原问题和修复

AMOLED 的洗澡交互只接入了简化泡沫规则：单个泡沫可以升级、缺少按等级向脚边滑落、精灵始终静止，泡沫透明度变化不一定触发重绘。冲水开始后直接隐藏全身泡沫，完成流程未调用回血。拖动时每次重复解码背景、精灵和底部按钮，并传输约 392 行，实机只有约 7 FPS。

本次将起泡、合并、滑落、下层计量、全身泡沫触发和冲洗降级抽至 `src/game/BathInteraction.*`，Stick 与 AMOLED 共用，AMOLED 保留触摸拖动和现有竖屏布局。

- 有效肥皂拖动累计 24 px，且间隔至少 180 ms，生成 1–2 坨，初始大小随机。静止或在身体区域外拖动不计有效动作。
- 有效刷洗累计 8 px，且间隔至少 150 ms，处理最近的泡沫；小泡沫 2 次，大泡沫 4 次，成长间隔至少 600 ms。
- 小泡沫只能与同一上下层的小泡沫配对；大泡沫需要同级并落稳，不能单独升级。落稳判断包含静止点偏移，修复了 Stick 原有的部分落点永远达不到合并要求的问题。
- 大泡沫根据精灵底部和泡沫高度按时间滑落，横向分散；仅下层以 1/1/2/4 权重计量，总量 >6 且至少一坨 stage >=2 时出现全身泡沫。
- 补上起泡/合并的小跳，刷洗概率转身，冲水抖动与溅水，奖励经验/爱心浮动，以及收尾动作/叫声。
- 心情奖励不显示数字文字，按实际增加值浮起爱心：1–2 点显示 1 颗，3–5 点显示 2 颗，6 点及以上显示 3 颗；心情已满时不显示。爱心从头部附近上浮淡出，同屏奖励爱心最多 3 颗，经验提示保留。
- 完成时先播放奖励爱心，结束后再显示洗澡评分爱心，避免两组爱心重叠。
- 冲水保持逐级消退和全身泡沫淡出，动画结束补清理帧，静止后停止持续刷新。
- 冲水完成按 1/2/3 颗心恢复最大 HP 的 45%/70%/100%，封顶最大 HP。与 Stick 一样可选择部分流程后冲水，获得对应评分；中途退出仍按已使用肥皂且未冲水完成判断。

拖动优化缓存静态背景与静止精灵姿态，工具移动只重绘旧/新工具位置并集；泡沫、反应、水流等动态内容按实际变化刷新。背景和精灵缓存各约 322 KiB，离开洗澡及相关升级流程后释放，分配失败时使用原绘制路径。局部重绘范围覆盖动态内容和工具缩放边缘。

肥皂消耗仍立即保存；阶段奖励合并到待保存状态，松手或中断/离开后保存，升级切场景前保存，完成回血后保存。保存失败保留待保存标记并重试。持续按住时若突然断电，该次尚未保存的阶段奖励可能丢失，肥皂已消耗的事实仍保存。

## 实机性能

设备：Waveshare AMOLED 1.8 V2；使用设备原来的 lite debug 配置。已备份设备配置，只刷应用，保留存档和资源。

`diag shower soap`、`diag shower brush` 使用固定 12 秒轨迹，通过真实 DOWN/MOVE/UP 处理逻辑执行，不消耗物品或发放阶段奖励。下列 FPS 基于成功 LCD 传输完成和真实墙钟时间。它测量实际硬件绘制/传输开销，不代表人工手指经过触摸控制器的完整延迟验收。

| 工具 | 修复前全程平均 | 修复后全程平均 | 修复后稳定拖动 |
| --- | ---: | ---: | ---: |
| 肥皂 | 7.5 FPS | 50.3 FPS | 约 52.8 FPS |
| 刷子 | 7.4 FPS | 42.3 FPS | 多个稳定窗口约 50–53 FPS |

修复后全程平均包含进入页面及泡沫合并/小跳等复杂帧。剔除前 3 个日志窗口后，肥皂平均 52.8 FPS，刷子平均 46.8 FPS。首次进入页面仍有一次约 160 ms 的背景解码/缓存准备，较重的反应和全身泡沫帧仍慢于纯工具移动。

- 肥皂平均绘制 105.03 → 7.00 ms，传屏 24.56 → 3.89 ms。
- 刷子平均绘制 110.63 → 11.78 ms，传屏 21.18 → 10.40 ms。
- 每帧平均传输像素：肥皂 144482 → 20448；刷子 144485 → 28227。

测量数据：`tools/out/shower-fix-20261014/performance.json`。过滤日志：同目录 `baseline-perf-filtered.log`、`final-perf-filtered.log`。
