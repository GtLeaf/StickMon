# 谷仓背包使用流程对齐

2026-11-02。保留已确认的圆屏三列布局，对齐微雪的道具使用流程；本批未刷机。

## 使用流程

- 回复、解除异常、复活：物品详情 → 使用 → 队伍选目标 → 显示效果 → 回背包。
  HP 在 500ms 内变化，随后停留 200ms；期间阻止重复点击，完成后返回列表并保留滚动位置。
- 战斗同样允许选择队伍成员；成功使用才耗一个回合，反馈结束后再交给野生方行动。
  使用无效、缺少库存或取消目标选择均不扣道具、不耗回合，失败时可重新选择目标。
- 神奇糖果接入共享经验服务和升级、进化、技能学习通知；只提升所选成员。
- 进化石检查所选成员的适性，播放已有进化流程；动画确认才提交进化并扣石头，取消保留。
  升级使用现有底部对话框与浮动小箭头；进化使用居中表面避开顶部导航，完成后触摸继续。
- 战斗食物详情显示“投喂”，点击直接向野生精灵投出，不增加是/否确认。
- 心之鳞片点击条目直接进入首位招式回忆入口；进入或取消不扣鳞片。
- 背包展示完整持有目录，包括食物、肥皂和贵重物品。不可直接使用的物品只提供返回；
  战斗中保留全部库存，点击不适用物品时提示不可用。
- 黄金喷雾、甜甜蜜只在探索的非战斗背包中使用；房间或战斗不激活、不扣库存。
  不复制微雪现有喷雾/蜜的不可达入口。
- 谷仓商店出售后只更新数量和余额，不显示“卖出 +金额”。

## 实现边界

完整目录和作用效果复用 `Game::ItemInventory`，由 `GameEngine::useTeamItem` 负责存档脏标记，
糖果复用经验升级通知，进化石复用延迟提交事件。队伍页新增默认关闭的目标选择接口，
仅圆屏消费；其他设备继续原有界面与交互。未修改存档 schema、设备音量或实机存档。

圆屏 `BagUi` 负责列表和详情，`TeamUi` 复用队伍卡片显示目标与 HP 动画，
`MenuItemFlow` 协调子页和成长流程。`ExploreScene` 在子页更新后接收异步结果，
保证无需额外点击即可结束回血反馈、恢复战斗。
