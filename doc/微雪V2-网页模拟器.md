# 微雪 V2 网页模拟器

本地实现日期：2026-10-17。微雪 V1、Claw 远程聊天及设备硬件模拟不在本次范围。

## 运行内容

`src/platform/web/main_amoled.cpp` 运行真实 `AmoledApp`，与微雪固件共用游戏、界面、资源及 SaveCodec；画布和触摸坐标均为 368×448。网页入口源为 `web/amoled-v2/index.html`。

支持鼠标/触摸、拖动、音频、静音、自动保存、重启和确认后清空当前目标存档。失焦、页面隐藏时暂停逻辑时钟，关闭面板时请求保存后销毁 iframe；页面退出尽量同步保存，异常强退最多损失最近一次自动保存后的进度。每 15 秒尝试保存一次，游戏原有保存路径也保留。

游戏内锁屏与空闲锁屏请求在网页中表现为“暂停试玩”，可通过“继续试玩”或点击屏幕恢复，不执行设备深睡。

微雪存档前缀为 `stickmon_sim:stickmon:waveshare-amoled-1-8-v2:`，不复用 Stick 的 `stickmon_`。同一浏览器只允许一个微雪实例写入，第二个页面提示关闭其他实例。需要支持 Web Locks 的浏览器，通过 HTTPS 或 localhost 打开。

存储拒绝/空间不足会提示保存失败；损坏或未来版本存档保留并写保护。用户可确认清空后重新开始。重启与清空是不同操作；网页存档不与实体机同步。

Wi-Fi、ESP-NOW、PMU、真实 OTA 和远程聊天不可用；网页运行层拒绝开启无线会话，OTA 处理器不注册。试玩不能替代真机验收。

## 构建与本地发布

需要 Python 3、Node.js（刷机站要求 >=22.5）及可用 Emscripten；使用已有 emsdk 时先加载其环境。

```sh
bash tools/build_web.sh --target amoled-v2
bash tools/build_web.sh --target sticks3
python3 tools/publish_web.py --flasher /path/to/stickmon-flasher
```

只更新微雪：

```sh
python3 tools/publish_web.py --flasher /path/to/stickmon-flasher --target amoled-v2
```

构建输出位于 `build/web/<target>/`，分别包含 index.html、JS/WASM/data 和 build-info.json。每个目标有独立对象缓存。微雪目标将 `ui_amoled.smonfx` 映射为运行时的 `ui.smonfx`；构建时校验原生 UI 包。

发布器先暂存、哈希化并验证全部指定目标，再复制哈希文件，最后原子替换入口。保留旧哈希文件供已缓存旧入口的浏览器完成加载。旧版本清理应另择维护窗口，不在发版脚本中立即删除。

入口：

- Stick：`/assets/sim/index.html`
- 微雪 V2：`/assets/sim/stickmon/waveshare-amoled-1-8-v2/index.html`

本地发布脚本只写刷机站工作树，不推送 Git、不更新线上服务器。

## 刷机站登记

刷机站启动时，如果已有 StickMon × 微雪 V2 组合且微雪产物完整，会自动补登记模拟器。默认设备 slug 为 `waveshare-amoled-1-8-v2`；自定义设备 slug 沿用 `OTA_DEVICE_SLUG`。已经停用或自定义过模拟器的组合不被覆盖。

尚无设备记录时，先使用管理端原有设备/组合流程建立实际的 V2 设备；不会因为一个试玩包而自动新建或覆盖烧录模板。启动后新建的组合可在管理端“模拟器”页点击“登记并启用”，目录填 `stickmon/waveshare-amoled-1-8-v2`。启用时校验路径、入口、JS、WASM 和 data，文件缺失返回明确错误。

站点后端改动需重启；静态产物更新不需要重启。两仓库首次上线应先合入刷机站的校验/发布脚本支持，再合入固件仓库的构建工作流。

## 自动发布

`.github/workflows/release-simulator.yml` 从当前同一提交构建两目标，固定 emsdk 4.0.15，验证后推送刷机站 `public/sim/`。Web 适配源码已进入当前源码树，不再由发布流程临时合并旧 `web-simulator` 分支。仍依赖 `FLASHER_PUSH_TOKEN`；推送产物后，部署机需要拉取新版本。本次没有触发远端工作流或部署。

## 验证记录

- 本机 Emscripten 6.0.9-git：StickS3、AMOLED V2 两个 WASM 构建通过。
- 三目标固件：StickS3 release、AMOLED V1 Lite、AMOLED V2 Lite 构建通过。
- 48 项 AMOLED 原生渲染测试、存档编码/迁移测试和 12 项架构边界测试通过。
- `python3 tools/test_web_simulator.py` 覆盖独立尺寸、受控时钟、取消触摸不触发点击、无线不可用及按命名空间清理。
- 刷机站 `node --test tests/*.test.js` 覆盖 OTA 原有测试和模拟器包完整性、路径/符号链接、哈希入口改写、旧资产保留、缺包不发布、登记规则及公开/管理 API。
- 浏览器检查：设备选择、真实游戏画面、点击/拖动/菜单、静音、重启恢复、收起重开恢复、多页面互斥；320px 与 375px 宽度无横向溢出，画布按比例缩放。

尚未验证：真实 Android/iOS 设备、Safari/Edge 浏览器、远端 CI 的固定工具链及线上发布。当前本地包包含既有未提交游戏功能，build-info.json 明确记录 sourceDirty；正式版本应从已审核提交重新构建。
