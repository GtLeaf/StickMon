## 当前接入内容

- 使用最新 Chrome 工程同步的 18×17 市集和现有素材。四只常驻为变隐龙、耿鬼、袋兽与吉利蛋；候选为原四组结伴加单只信使鸟、玛力露丽、巨钳螳螂。皮丘不再常驻，仍保留于皮卡丘＋皮丘访客组。
- 横屏／谷仓与 AMOLED 的玩家和健康同伴均可在道路与可通行草地漫步。访客从地图入口走入，在摊位附近道路随机停留、回头和离开；不将两只访客挤进已有常驻精灵的两格区域。
- 常驻精灵保留工程中的出生点、活动范围与步速，停留调整为 3～6 秒。接待朝向独立配置，空闲时偶尔侧看／回身，游客到点后双方停下回应。
- 所有角色共享动态格子预约；脚底不占用同一导航节点，树冠与摊棚依既有图块深度遮挡。横屏／谷仓精灵用原动画 1× 和原脚底锚点；AMOLED 自由行走地图与精灵使用 1.5× 最近邻缩放，39×39 图块，脚底锚点保持。
- 市集是独立临时会话，不触发普通探索扣费、遭遇、Boss、拾取或通关奖励；保留游客与摊主的气泡交流和轻跳演出，微雪／谷仓增加点击聊天的文字对白，交易或节日日期逻辑尚未接入。
- 选择市集后先回到房间，复用探索的走到门口、穿门、渐隐及市集渐显；同行成员使用原出门流程。全黑后才创建市集，渐显期间暂停行走，不记录探索时间或次数。
- 锁屏冻结活动和动画，恢复不追补锁屏时长。触摸设备的玩家走回地图出口后，玩家和同伴沿入口离开，经全屏渐隐返回房间；进图时不会立即退出。

## 调整列表位置

维护文件：`src/game/ExploreDestinations.h`。

```cpp
inline constexpr uint8_t ORDER[] = {MARKET, 0, 1, 2, 3, 4, 5};
```

只重排此表即可移动市集或其他地区。每项保留一次：`MARKET` 是独立目的地，`0～5` 是原六地区的稳定编号。列表位置通过目录映射到编号，原解锁顺序、Boss 计数和存档数组仍按稳定编号工作；重排无需迁移存档。

例如把市集放在原第二区之后：

```cpp
inline constexpr uint8_t ORDER[] = {0, 1, MARKET, 2, 3, 4, 5};
```

菜单仍按原进度过滤地区，不会因显示顺序调整提前解锁。不要为移动列表位置改 `Game::EXPLORE_AREA_COUNT`、`ExploreAreaCatalog` 的地区编号或存档字段。

## 调整地图、入口和精灵位置

正式维护源是 `origin_asset/maps/market/market.stickmap.json`，生成数据是 `src/game/MarketMapData.h`。工程保留图层、完整物件、入口、活动范围及候选池；生成头不作为手工编辑源。

1. 在地图编辑器打开正式维护源或自己的草稿，修改摊位、道路、入口、常驻出生点或活动区域。
2. 修改图层／物件后重新“识别道路”，再“存为路线”；变更入口后也重新保存道路路线。入口需位于选定边界并与路网接通。
3. 检查活动配置，使用“预览活动”和“正式绘制器预览”确认可达性、进出与遮挡。素材来源变化时，先核对画面再更新来源记录。
4. 下载工程，在仓库根目录执行：

```sh
.stick-local/venvs/map-editor/bin/python tools/map_editor/market_export.py 新工程.stickmap.json --install
```

此命令先校验，再同步正式工程和生成头。它不会修改原编辑器草稿，也不会自动构建或刷机。若已人工核对来源变化，可显式追加 `--accept-source-update`；不使用该参数时来源哈希不一致会阻止导出。

维护源本身修改后，也可执行：

```sh
.stick-local/venvs/map-editor/bin/python tools/map_editor/market_export.py origin_asset/maps/market/market.stickmap.json --install
```

现有已接入图块无需额外资源扩容；引入尚未接入的素材仍需走项目资源管线，并同步相应资源包。调整完重新运行下方检查与受影响固件构建。

## 操作与设备

横屏／谷仓：地图与精灵以运行时 1× 展示，不显示地图名、弧形血条或底部黑栏。谷仓使用 360×360 原生视口，地图高于／低于视口时按相机裁切／延展边界地面，不拉伸图块或重复物件。

触屏在地图上按下时，以该按下点为中心出现浮动摇杆，八向等速行走；松手后隐藏，下次按下重新定位。保留 8px 死区、5 度方向滞回和 26px 摇杆位移上限；松手、取消、越出屏幕、按键和锁屏清空方向，已经开始的半格步行会收尾。地图轻点不会立即行走，也不自动寻路。聊天按钮优先接收按下，整次手势保留归属：拖离按钮不转成行走，拖动摇杆经过按钮不触发点击。暂停、对话或离场时不接受新的摇杆输入。右上角菜单及其暂停／返回弹层已移除，该区域恢复地图摇杆操作。

走回正式工程定义的出口（`entry`）并向外移动即开始返回，不需要点按钮。出口宽度取同一边界上与 `entry` 连续相接的道路半格；当前入口的左侧、正中和右侧均可触发，不再仅限正中半格。已经站在入口时向外也可离场；进场等待不会自动离场。其他边界和同边断开的道路仍不可作为出口。出口被同伴占据时，使用现有预约和离场流程让同伴先通过，玩家随后走出地图；没有重叠或瞬移，离场完成后经全屏渐隐返回房间。该行为用于手动漫步模式，AMOLED V1/V2 现也启用。

玩家靠近常驻或访客 NPC 32px 时，底部出现聊天气泡图标，远离到 44px 后隐藏；隔墙或隔摊位不显示，自己和同伴不作为目标。28×28 图标四周各留 4px，背景为 36×36，独立 44×44 点击区保留操作余量。微雪／谷仓点击后锁定按下时的 NPC 及其真实同行者；双方完成当前半格并转向，打开底部对白。访客必须已经进入正式游逛阶段；尚未入场或正在离场的组合不作为对话目标。返回时玩家与同伴按各自位置回到入口，保留完整离场。

聊天图标由内置 image_gen 生成，透明底、奶白气泡、深蓝描边和三个点。源图与完整提示词分别保存于 `origin_asset/icon/market/chat-generated.png` 和 `chat-source.json`；`tools/prepare_market_chat_icon.py` 保留透明度并以最近邻缩为 `chat.png`（28×28）。按现有资源管线追加 `MARKET_CHAT`，由 `generate_game_assets.py --only ui` 打入共享 UI 包，AMOLED UI 包同步转换。旧 Kind 编号与既有图标保持，旧资源包缺少新帧时回退“聊天”文字。

StickS3：A 前往当前标记点，B 切换目标，长按 B 返回；到达后可选择下一处，不强制遍历整条道路。锁屏仍由原设备流程处理。

AMOLED V1/V2 共用 `MarketWalkUi`：1.5× 地图铺满 368×448，当前18×17地图为702×663像素；移除整个底栏与旧的道路点击寻路操作，按住地图定位浮动摇杆、松手停止并隐藏。靠近 NPC 时底部居中显示 72×72 聊天气泡，位置 (148,363)，图标56×56，点击区88×88，保持底部13px间距；远离后隐藏。地图倍率和控制按钮倍率独立，谷仓仍为36×36按钮。锁屏当下取消摇杆与行走方向，恢复后需要重新按下；触摸取消、越界与离场也清除方向。聊天仍仅消费点击，未新增对话业务。谷仓和 Stick 共用横屏场景适配。OSTB 已暂停，本轮未构建其固件。

## 绿荫镇音乐

进入市集请求 `MusicTrack::MARKET`，返回房间恢复房间音乐；沿用用户音量，音量 0 时保持静音。原 MIDI 来自 [pokeemerald](https://github.com/pret/pokeemerald/blob/master/sound/songs/midi/mus_verdanturf.mid)，绿荫镇地图明确使用 `MUS_VERDANTURF`。维护源和哈希记录位于 `origin_asset/audio/emerald/`。

采用现有 Essentials `soundfont.sf2` 转制，旋律和编曲来自原 MIDI，音色不同于 GBA 原硬件。完整保留 46.25 秒前奏加循环，循环起点 0.53575 秒，没有套用旧生成器的 30 秒截断。使用 8kHz 单声道 IMA ADPCM（186404B），播放时流式插值至 16kHz，以满足谷仓 3MiB 构建体积限制；已有曲目未重新生成。

```sh
.stick-local/venvs/map-editor/bin/python tools/generate_market_audio.py --soundfont "$ESSENTIALS_DIR/soundfont.sf2"
```

此工具依赖 `mido`、`fluidsynth` 和 `ffmpeg`。谷仓只额外打入 `bgm_market.smonaudio`，未扩入所有旧音乐／音效。
