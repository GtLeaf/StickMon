# 锁屏房间省电验收

日期：2026-10-16，更新于 2026-10-17。范围：AMOLED V1/V2。用户明确排除降低屏幕亮度。

## 已实现

- 稳定锁屏房间每 100ms 更新逻辑；活动画面上限 5fps；睡眠圆环上限约 15fps，其他房间内容按 500ms 节流，睡姿变化优先呈现（正常 800ms/帧，濒死 700ms/帧）。
- 遮罩外的标题/状态变化不传屏；可见更新使用矩形裁剪绘制与传输。
- 房间移动按经过时间分步推进，游戏时间、自动进食、回血与照料继续结算。
- 房间空闲释放 CPU 高频锁，允许 80–240MHz 动态调频；解锁/复杂场景恢复高频。
- 触摸 GPIO 电平唤醒并通知主任务；持续按下时屏蔽电平中断、每 20ms 检查，避免中断风暴。无有效触摸唤醒源时禁止自动浅睡眠。
- 空闲音频关闭 codec/I2S 输出，下次播放重新打开；退出 ESP-NOW 时停止 Wi-Fi，Claw 按已有离开联机流程恢复网络。
- 原屏幕亮度与存档格式保持不变。USB 连接时通过 IDF 保护锁禁止自动浅睡眠，以保留串口调试。

- 相关调度、触摸、锁屏、布局、渲染需求、音频和架构测试：46 项。
- 原生应用与画面测试（开启渲染诊断）：47 项。包括锁屏一小时、跨日额度、自动进食获得经验、保存重启、亮度不变；局部矩形与完整画面逐像素一致，矩形外保持不变。
- V1/V2 的 Lite Debug、Claw Debug 共四种构建通过。
- PM 配置确认开启；USB 防浅睡保护、Tickless Idle 开启，启动时自动 DFS 关闭，统一由应用在初始化完成后启用。

实测使用 V2 Lite Debug，测试构建的本地 sdkconfig 开启 `CONFIG_PM_PROFILING=y`（发布构建默认关闭，不增加发布版统计开销）：

- 未锁屏诊断：`locked=0`，CPU 240MHz，房间 CPU/禁止睡眠锁均持有。
- 锁屏诊断：`locked=1 sleepAllowed=1`，房间两把锁均释放；I2C/SPI 空闲锁未持有。USB 禁止睡眠锁持续持有，浅睡眠次数保持 0，符合 USB 调试保护策略。
- 稳定睡眠画面的两个快照相隔约 30.010 秒。80MHz 的累计时间从 3,490,417us 增至 28,002,074us，差值 24.512 秒，占观测区间约 81.7%（提高呼吸环帧率之前的策略，不能代表当前策略）。这证明实际发生降频，不代表整机耗电降低 81.7%。
- `diag power` 执行时会持有 RTOS 高频锁，因此即时频率仍显示 240MHz；空闲降频用 PM 模式累计时间的差值验收，不能用诊断执行瞬间的频率代替。
- 物理双击：155192ms 与 155412ms 收到两次触摸，155432ms 进入解锁、恢复高频锁，156452ms 完成解锁；用户确认完整房间画面正常。之后 `diag power` 返回 `locked=0 sleepAllowed=0 cpu=240MHz`，房间两把锁重新持有。
- 锁屏持续两分多钟，游戏分钟从 1386 增至 1388，无崩溃记录；正常醒来后继续推进。
- Lite 的无线恢复：两次进入搜索页面均启动 Wi-Fi/ESP-NOW，两次退出均记录 `Visit radio stopped: ESP_OK`，第二次可重新启动。只验证本机搜索/退出，未连接另一台设备，不代表双机联调通过。

## 10 月 17 日同步呼吸调整

呼吸环和睡姿共用入睡时钟，两帧 1.6s 一轮。圆环目标约 15fps；半径取整后无像素变化不重复传屏。单独圆环帧复用快照，不重画精灵，也不吞掉等待处理的房间脏区。内容快照覆盖最大呼吸范围，中心按全部睡姿并集确定。睡姿舒展方向按可见高度/宽度匹配，相同边界默认首帧，复杂姿态仍需肉眼验收。

自动验证：46 项相关检查、47 项原生应用与画面测试通过。新增相反睡姿顺序（卡咪龟/卡比兽）、稳定圆心、锁屏/唤醒相位连续性、单帧素材、时间回绕与漏帧后追齐。V1/V2 Lite/Claw Debug 四种最终构建均通过。

V2 只刷入 Lite Debug 应用（哈希校验成功），保留 NVS/资源/分区表；烧录前再次备份 NVS。设备启动后通过现有锁屏按钮进入锁屏，连续采集约 65 秒：

- 圆环以 67ms 为最短检查间隔，实际可见传屏 11.4～13.6fps（约 12.4fps）；半径取整导致极值附近重复画面被跳过。
- 内容实际重绘约 1.8～2.6fps，包含 800ms 睡姿切换与其他房间脏区；圆环其余帧复用快照。睡姿优先切换会越过房间内容的 500ms 普通节流，故内容总重绘可略高于 2fps。
- 主精灵为卡咪龟，处于实际睡眠；半径在 58～74 之间，观测到两个睡姿和缩放变化。游戏分钟从 1427 推进至 1428，无崩溃或传屏错误记录。日志不能替代肉眼观感验收。
- 两次 PM 快照相隔 30.050 秒：80MHz 的 APB_MIN+APB_MAX 时间增加 19.470 秒，占约 64.8%；USB 浅睡保护仍持有，浅睡次数 0。此比例只表示 CPU 低频驻留，不能当作整机省电比例。提高圆环刷新率后低频驻留较先前策略减少，符合更平滑动画的取舍。
- 本轮未再次物理双击验收；手势代码未改，原生手势/睡姿焦点测试通过，前次实机双击结论仅属于前次固件。
