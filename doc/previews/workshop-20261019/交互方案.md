# 工坊交互概念 v1

日期：2026-10-19。设计提案，尚未接入游戏。

概念图：`workshop-flow-v1.png`。使用内置 image_gen 生成，完整提示词见 `prompt.txt`。
参考了当前伙伴页、房间菜单，以及森林系列房间和家具原图。屏幕按 368×448 比例组织。
图中探索地图及制作小场景是概念美术，实际开发复用现有地图与精灵资源。

## 入口

- 房间菜单增加「工坊」，现有「家具」负责更换已经拥有的家具。
- 工坊有「配方」「制作」两个页签；有未查看的新配方时显示「新」，制作完成时给制作页签提示点。
- 返回保留列表滚动位置。首次点击新配方后清除该条目的「新」。

## 六步交互

1. 探索发现：配方自动收录，底部 HUD 显示「发现配方 / 叶片地毯」，不中断移动；无需确认或领取。
2. 工坊列表：每行展示家具缩略图、名称、状态及进入箭头。状态包括「材料不足」「可制作」「制作中」「已拥有」。未发现配方放在列表后部，显示剪影及发现来源。
3. 配方详情：上方家具预览，下方材料图标、已有/需要数量和来源。点击材料行查看获取地点。材料不足时主按钮「追踪配方」，再次点击可取消追踪；全局最多追踪一张。材料齐全后主按钮为「制作」，进入制作方式选择。
4. 找伙伴：顶部始终提供「自己制作」，其余为可帮忙的伙伴；每行显示头像、名字、预计耗时，擅长时显示简短说明。点击整行选择，底部「开始制作」提交。默认选择自己制作；返回不消耗材料。示例自己制作 3 分钟，妙蛙种子帮忙 2 分钟，具体数值待平衡。
5. 制作中：展示家具、帮忙伙伴和数字倒计时。「继续探索」回到探索入口，若当前无法探索则说明原因；常规返回回到工坊。离开页面、锁屏后计时继续。第一阶段一个制作任务，不设置付费加速或随机失败。
6. 完成摆放：家具完成后自动加入收藏；制作页展示完成卡片，点开出现概念图中的完成页面。「立即摆放」更换对应家具槽并返回房间，底部 HUD 提示「已摆放」；「稍后」回工坊，家具仍在收藏中。

## 关键状态与边界

- 点击「开始制作」时重新核验配方、材料和任务空闲状态，成功后一次性扣材料并保存；重复点击不得重复扣除。失败停留在当前页面并给出原因。
- 开始后返回、退出菜单不取消任务；首版不提供取消制作，避免误触和材料退款歧义。
- 伙伴从已结交的永久伙伴中选择，不要求加入队伍，不占房间或队伍名额，不阻止其原有照料与战斗行为。一次只记录一只帮忙伙伴。
- 第一阶段擅长带来耗时加成，不强制指定精灵、属性、好感等级。助手在开始制作时确定，中途不更换。
- 等待以实际经过的时间计算，不使用加速的游戏内分钟。锁屏计时继续；关机离线是否推进另行确定，概念图不承诺关机离线结算。
- 制作完成不强行打断战斗、探索或洗澡。安全页面显示底部 HUD 通知，制作页保留完成记录。
- 家具每款首次制作后永久拥有，可重复摆放。普通配方不需要重复制造，已拥有状态的详情主按钮变为「摆放」。
- 材料已齐但有制作任务时，详情显示「制作中」，点击前往当前任务，避免到最后一步才发现被阻止。
- 更换预览允许取消；最终确认摆放后保存选择。昼夜窗户作为同一家具拥有，按时段切换外观。

## 首版范围

先做森林地毯、食盆、置物架、床、窗户，固定槽位替换；首张配方保证获得，材料保证能完成一次引导制作。后续扩展星月、云朵、挂画和抱枕。
