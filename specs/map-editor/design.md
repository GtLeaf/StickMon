# 地图编辑器设计

## 技术与交互

`tools/map_editor/` 使用 Python/Pillow 本地服务、无构建步骤的 ES modules 和 Canvas 2D。素材库、中央画布、属性面板与问题列表采用深灰工具台、绿色选中态、琥珀色兼容提示；中文苹方，数字 Menlo。

`model.js` 管理命令历史、图层合成和路线几何；`app.js` 管理工作台。`project.py` 管理 schema、快照、校验与编译；`catalog.py` 管理原素材、别名、动画及共享 C++ 语义；`serve.py` 暴露本机 API。

## 数据权威

工程 JSON schemaVersion=1，保存 sources 哈希、catalogVersion、prefabs、map 与 origin。基础图层保存限定来源的素材键；物件实例单独保存，合成时逐层展开。实例同层同格冲突会阻止导出。移动物件不改写基础图层。

内置物件共享落地点；多物件复制和原图取样保留各图块原生深度。自定义锚点、占地不能映射既有规则时允许保存，阻止导出。快照导入按共享落地点与连通树片恢复树木/树群，合成指纹不变。

编译输出 AuthoredMap.h、运行时 JSON、素材需求、工程源与验证报告。C++ 头不是编辑源。河谷和跨图转场保留字段，但需地图组连接验证后才能导出。

## 资源与验证

`tools/map_editor_assets.py` 是编辑器图块来源与深度的权威表，生成 ExploreEditorTiles.h。Kind 只追加，别名从 11000 开始，GameAssets 和 ExploreTileSemantics 共享。2026-10-28 扩充后共有 156 个图块、159 个资源帧；旧 71 个编号与深度保持不变。地图包 874 帧、3834 palette words、105138 data words、237172 raw bytes，上限保持 896/4096/200000/384000。旧 789 帧记录、数据与调色板逐字节不变。注册表与物件矩阵分离，重复源图但不同落地深度使用独立素材键（如 `slateport:738:d3`），不覆盖旧别名。

集市中绿宝石来源的 16 种完整物件由 `tools/slateport_market.py` 维护。原始 16px 前景使用原调色板/翻转标志拼合，再最近邻放大为 32px，保留透明索引；原文件与哈希收录在 `origin_asset/source_maps/slateport_emerald/`。气球引用四帧原序列，每帧约 280ms，第二/第四帧同为回正姿态。AMOLED 缓存重绘逐格恢复地面到前景，避免透明帧残影；Stick/OSTB 从原 140ms 地图时钟取双 tick，保持相同气球节奏。正式预览附动画 GIF，PNG 保留静态含义。

原生 host 复用正式 Map 指纹和 pathPoint。正式预览使用当前资源包、GameAssets 与 AMOLED 探索绘制器，并逐个核对新增图块在角色脚底前后的遮挡像素。

服务仅绑定 127.0.0.1，校验 Host/Origin 和会话令牌。工程原子保存到 `.stick-local/map-editor/projects/`；浏览器草稿只是备份。构建与验收文件进入 `.stick-local/`。

## 2026-10-28 素材库修正

按用途合并集市类别；浏览旧工程时仅归一化分类显示，不覆盖自定义组合。旧缺片伞定义作为隐藏兼容项保留，完整版采用新 ID 和 2×3 结构。旧工程中替换伞需重新放置，避免自动扩展占格。单格鲜花与旧三格组合并存。新增 Essentials 树木/货车/围栏、绿宝石躺椅及已有水岸组成的湖泊，共 64 项可见预设。湖面和岸角均在 L0，水体分类与无桥通行校验沿用正式规则；其余物件使用 L1 和共同落地深度。

## 2026-10-28 自动湖泊

`lake.js` 在编辑阶段按 N/E/S/W/NW/NE/SE/SW 八邻格匹配；仅在相邻两个正交方向均有水时保留对角位，256 种邻接情况归并为 47 种。点击孤立空地生成 3×3，邻水点击和拖动增加一格，退水重算相邻岸线；一次笔触只产生一个历史记录。完整纯水 L0 组合可转为自动水域，混合组合或非水域完整地面物件先拒绝操作。自动铺湖记录 `map.lakeGround`（字符串格索引到原素材键），退水恢复原地面，普通笔刷覆盖时清理失效记录。服务端复核岸线与恢复数据，沿路线铺路后也重新修岸。

`tools/lake_autotile.py` 拼接原 Sea 四分块并追加 ID 12000～12046，每种 8 帧；编号由固定方向和排序后的规范掩码确定。生成 ExploreLakeTiles.h，GameAssets 与正式水域判定共用此范围。导出只含普通图块，不在设备上运行自动铺岸；湖泊动画重绘恢复地面到前景，避免擦掉物件。

当前地图包为 1250 帧、5336 palette words、151686 data words、341544 raw bytes、75937 packed bytes；对应上限 1280/6144/200000/384000。前述 874 帧记录、像素数据与调色板逐字节保留。Python/JavaScript 对全部 256 种邻接输入交叉验证；正式绘制 host 检查 47 种水域全部 8 帧、有无前景时缓存与干净合成一致。验收目录 `.stick-local/artifacts/map-editor-autolake-20261028/`，未刷机。

## 2026-10-29 集市物件旋转

首批六种：格纹／条纹长桌、花苗长箱、木货箱、绿／蓝躺椅。`map_editor_rotations.py` 冻结源矩阵和每种 90/180/270 度方向，分配 13000～13074 共 75 个图块；Kind 和资源帧在自动湖泊之后追加。原像素按 90° 精确置换，32px 拼合结果与整物件旋转逐像素相同；26px 游戏资源由同一源图最近邻生成。三款遮棚对照发现棚柱横躺／倒置，未开放；其他类别未纳入本批。

工程仍使用 schemaVersion=1 的普通组合引用，原方向定义不变；另外 18 个隐藏方向变体有独立尺寸、底部锚点与底行占地。ExploreRotatedTiles.h 提供共享深度，正式绘制、路线占地校验和编辑器预览同步。按钮／方括号快捷键在放置模式切换预览，在选择模式只转单个物件；以左上格为基准，保持位置，整体预检边界、同层冲突及锁定后提交一个可撤销命令。旧工程按需追加方向定义，自定义几何不覆盖，组合库已满时拒绝追加。

本批地图包 1325 帧、5654 palette words、162180 data words、364818 raw bytes、79198 packed bytes；帧上限增至 1536，其余上限仍为 6144/200000/384000。前 1250 帧的记录、像素和调色板逐字节保留。测试覆盖六种四向像素、Python/C++ 导出、旧图读取、撤销重做、越界／重叠／锁定拒绝以及正式绘制器 75 图块遮挡。验收目录 `.stick-local/artifacts/map-editor-market-rotation-20261028/`；任务跨日，目录沿用开始日期。
