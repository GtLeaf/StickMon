# 设计

地图可选字段 activityZones 和 npcs；各最多 16 项，区域 192 格，单 NPC 最多 32 巡逻点。旧 schemaVersion=1 增量兼容，暂不改既有 Map 二进制布局。

区域格集合可以重叠。NPC 独立 ID，scope=zones/map；静态配置与瞬时位置分离。共享 C++ AuthoredNpc.h 使用固定数组、四向 BFS、确定性种子、固定 100ms 更新步长、目标格预约与停留重试。浏览器调用本机同一 C++ 核心生成 120 秒时间轴并回放，不另写 JS 行为模拟器。有限预览到末尾停止，暂停/恢复不重置，编辑时使旧时间轴失效。

服务端从当前图块语义与物件 footprint 生成通行网格；水域需桥面，原始物件落地深度=1 阻挡，完整组合使用显式占地。区域并集与网格取交；出生点、巡逻点及连通性校验。无可靠地面语义的图块保守阻挡。

导出除原地图数据外增加活动 JSON、AuthoredNpcs.h、共享核心和实际使用的人物 PNG/来源哈希；不强行接入既有生态模拟器。现有正式地图场景尚无自定义地图选择/人物资源加载入口，接入边界在导出 README 明示。

界面为工具型工作台，保持既有三栏与 PingFang SC / Noto Sans CJK SC。色彩：#171c1a 背景、#222a26 面板、#a9ce90 选中、#e7b66a 提示、#e9eee4 文字。右侧“区域与 NPC”面板，区域/NPC工具切换时展开；不改原素材库。矩形、涂抹、擦除用于区域；点击放置、拖动出生点、点击设置巡逻点用于 NPC。按脚底深度绘制并重覆前景，标记与地图像素分开。
