# 活动区域与 NPC 第一版

用户已批准：区域绘制、NPC 放置、原地/散步/巡逻、单地图自由活动。

- 旧地图无区域/NPC 字段时继续正常加载、保存、导出。
- 用户矩形框选或逐格涂抹区域时，应保存独立稳定 ID、名称、颜色和格子集合；允许重叠。
- 用户新增 NPC 时，应保存独立 ID、名称、原素材外观、出生点、朝向、区域列表/全地图、行为、步速、停留范围和巡逻点。
- NPC 只能在关联区域的并集与可通行地面交集中移动；全地图模式也遵守水域、物件占地和边界限制。
- NPC 不可互相占据同一目标或对穿；堵塞时等待再尝试。巡逻目标不可达时应明确报错。
- 编辑与区域删除、NPC 删除均可撤销；删除被引用区域不悄悄扩大 NPC 活动范围。
- 预览支持播放、暂停、重置；预览姿态不写回地图出生位置。
- 工程、游戏源数据导出保留区域/NPC，不静默丢弃；共享活动核心供编辑器和后续设备端接入使用。
- 不添加测试地图到用户工程列表。此次不自动替换正式游戏地图，不加入对话、交易、跨图日程。
