# OSTB 圆角屏布局规则

更新日期：2026-10-21。当前规则以用户最新反馈为准：**只给顶部导航栏增加左右圆角边距，正文按原布局正常延伸到屏幕两侧。** 不再把整页内容限制在 240px 宽的安全矩形中。

## 当前实施范围

本批仅调整队伍及其状态、技能、蛋、回忆／替换、确认弹窗与提示。状态和技能保留原内容排布，只增加顶部返回导航；状态页指示器在底部居中覆盖绘制，不为它挤占正文；底部不显示选择／确认或上一页／下一页操作栏。其他页面组的统一圆角调整继续暂缓。

## 几何规则

使用原生横屏 296×240 坐标，矩形采用左闭右开、上闭下开范围。

| 区域 | 当前范围 | 规则 |
| --- | --- | --- |
| 顶部导航 | y=[0,48) | 返回和标题向内避让圆角 |
| 顶部关键内容 | x=[28,268), y=[4,44) | 左右 28px 边距仅用于导航，不下传给正文 |
| 顶部返回点击区 | (28,4,40,40) | 圆心 (48,24)，可见半径 16px |
| 正文视口 | (0,48,296,176) | 使用完整 296px 宽；顶部边距按最新要求为 4px，正文上移 12px；下沿仍为 y=224 |
| 队伍卡片 | (8,52,280,76)、(8,136,280,76) | 采用普通 8px 内边距，卡片可延伸到原 28px 边距内 |
| 技能列表 | x=[0,90), y=[54,218) | 原 90px 左列、24px 行，详情从原 x=97 开始 |

1. 顶部安全边距为 4px，返回圆形从 y=8 开始，标题从 y=16 开始；导航栏总高 48px。顶部标题右边缘不超过 x=268，与返回点击区至少间隔 8px。长标题在导航范围内截断；导航以外的角落不提供隐藏点击目标。
2. 正文不继承导航的左右边距。状态字段、精灵图、技能左右分栏和页点保持原排布与像素尺寸；文字可用宽度按 296px 视口计算。禁止为规避圆角缩小整帧或改触摸校准。
3. 队伍卡片、正文列表、弹窗和提示按各自原布局或普通内容间距绘制，不受统一 28px 横向限制。背景可以铺到两侧。
4. 绘制、点击、滚动和物理按键 reveal 共用正文布局。两侧原留白区域内的可见卡片／列表必须可以正常点击；不能只扩宽画面却继续屏蔽边缘触摸。
5. 状态保留左右滑动或点顶部标题翻页，上下拖动超出内容；五个指示点改为底部居中，在正文之上绘制，不留底部操作栏；技能点条目查看，再点当前项执行既有动作。遗忘保留默认 No 的确认窗，弹窗阻止穿透，拖动／取消不执行动作。
6. 房间仍为 240×161、原点 (28,39)、1 倍显示。房间居中与菜单导航边距是两个独立规则，本批不改变房间比例、玩法或存档。

## 共用布局与验证

`TouchUi::safeHeaderBounds/safeBack` 只定义顶部导航的安全几何；`TouchUi::pageBody` 定义完整宽度的正文视口。不得再用顶部范围统一裁切整页或拦截正文触摸。

自动检查覆盖顶部边界、原正文全宽像素对比、两侧卡片点击、左侧技能点击、从边缘开始的状态滑动、弹窗隔离和底部无隐藏操作栏。导出图可叠加圆角遮罩供观感检查；R=56px 和 6px 轮廓余量仍只是未精测的预览参数，不作为收窄正文的依据。

实机重点确认顶部返回／标题不裁切、正文正常延伸到两侧、触摸位置一致。全站圆角适配仍需后续按页面逐项验收，不能用本批软件检查宣称所有页面已完成。
