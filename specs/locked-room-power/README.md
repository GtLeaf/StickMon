# AMOLED 锁屏房间省电

更新：2026-10-26。当前调度与电源契约；Claw 专项随功能迭代暂停。

## 行为要求

1. 锁屏期间保持原亮度与精灵可见，完成双击后按原动画解锁。触摸响应独立于绘制帧率。
2. 锁屏房间活动按 100ms 调度；活动画面最多 5fps；睡眠呼吸环最多约 15fps，其他房间内容按 500ms 节流，睡姿换帧优先跟随共享呼吸时钟；无可见变化不刷新。时间、照料、进食与经验按经过时间结算。
3. 锁屏空闲 CPU 允许降至 80MHz，解锁或复杂场景恢复 240MHz；空闲时允许自动浅睡眠，触摸唤醒源不可用时禁止浅睡眠。
4. 退出联机释放无线；Claw 版由已有离开联机流程恢复需要的网络，正在联机不被锁屏断开。
5. 所有声音播完后关闭空闲音频输出，再次播放可自动恢复。
6. 保持现有存档格式。V1/V2 共用调度和省电策略，板级适配分别验证。

7. 呼吸环与主精灵睡姿共用时间源，睡眠每帧 800ms、两帧一轮 1.6s；濒死休息每帧 700ms。按睡姿可见高度/宽度选取舒展帧，边界相同时默认首帧。锁屏/解锁不重置呼吸时钟，睡姿范围的并集固定圆环中心。

## 设计与所有权

共享 LockPowerSchedule 管理 100ms 逻辑、200ms 活动画面、67ms 睡眠圆环、500ms 房间内容绘制时间与可见脏区判断；主循环触摸通过任务通知提前结束等待，按下期间保持 20ms 释放检查。房间更新按真实时间切分为不超过 100ms 的活动步，避免调度误差造成走慢。

共享 AmoledLockPower 使用 ESP-IDF PM 锁管理 80–240MHz 动态调频与自动 Light-sleep。非锁屏/复杂场景保持高频及禁止睡眠；稳定锁屏释放这两把锁。触摸 GPIO 配置为电平唤醒；SPI/I2C/I2S 的驱动锁保护事务。USB 连接期间阻止自动浅睡眠以保留调试串口，电池供电时可进入。亮度完全不参与省电策略。

锁屏只处理圆形窗口相交的脏区；不可见请求被消费，解锁全帧恢复。音频任务在混音及队列空闲后关闭 codec，释放 I2S/功放。ESP-NOW end 停止 Wi-Fi，Claw 在已有 leavePeerSession 中恢复网络。

测试覆盖调度、时间回绕、可见脏区、锁屏进食/时间/跨日、双击和部分绘制。V1/V2 Lite/Claw 构建，V2 实机核对启动、锁屏、亮度、频率、唤醒和存档。功耗收益需外接电流仪实测，不由电量百分比推算。

睡眠表现使用 SleepBreathClock，以入睡时刻为基准按实际经过时间取睡姿与连续余弦起伏。每张睡姿覆盖对应舒展/收缩极值，圆环在两帧之间插值；睡姿变更优先呈现，不受其他房间重绘延迟。单帧素材仍可呼吸。健康精灵只有实际入睡才启用圆环呼吸。

圆环帧从未遮罩快照恢复，保留未到房间内容刷新时间的脏区；只有实际重绘应用内容后才清除脏区。应用重绘时预先更新最大呼吸范围，防止下次扩大暴露旧像素。主循环等待逻辑与圆环两个截止时间的较小值，无像素变化的圆环检查也推进截止时间，防止忙等。
