# SDGOODS 硬件、电量与首次开机

更新：2026-10-26。合并硬件补齐与后续电量／正式首次开机规范，当前标准以本页为准。
圆屏菜单及页面表面见[菜单规范](../sdgoods-full-menu/README.md)，构建和 app-only 更新见

## 硬件与保存要求

1. 保存成功时，房间和菜单不再显示 Saved；失败仍有提示。
2. 启动、升级、锁屏和恢复时保留已存音量；当前实机音量为 0，功放必须关闭，不进行试听。PCM 三通道复用共享混音器，麦克风仅按需开启。
3. 电量按谷仓 SDK 的 ADC1 CH7、三倍分压采样，失败显示未知；百分比为估算。IMU 按需运行，洗澡始终触摸拖动。
4. 电源键按下去抖后先保存，按住暂停，短按锁屏／解锁，长按保存成功后关机／深睡。锁屏不改变存档亮度，失败不得主动关机。
5. 通讯页使用共享 ESP-NOW 协议和频道，退出释放射频；不加入 Claw／微信。
6. 升级只更新实测设备 OTA0，保留 NVS、OTA1、引导和分区记录。实机验证保留音量 0 与原档；双机互联、放电曲线与物理断电结果独立记录。

## 板级实现

延续无 LVGL framebuffer。SdgoodsPlatform 组合谷仓专属 Audio、PeerRadio 与 ADC，复用 common Qmi8658／PowerButton 和 core PcmMixer。板级初始化参考 SDK 固定引脚，不修改 SDK。UI 只移除保存成功提示并显示电池估算图标，玩法、schema、资源与通讯协议不变。

音频任务与主线程用 mutex 串行化，主音量初始 0；音量为 0 时 PCM 输出零且 PA 低。录音不改射频或主音量。电源锁屏独立保存亮度与静音状态，深睡先关闭外设并保持电源自锁，唤醒先拉高后解除 hold。沿用引擎现有闲置调暗策略。

验证覆盖静音／混音、按键保存与失败保护、ADC 边界、真实 UI／存档恢复／触摸洗澡、ESP-NOW 协议及谷仓构建；实机只 app 更新，音量保持 0。

## 电量与首次开机

1. 电池使用 SDK 的 3000–4280mV 线性估算、四舍五入并限幅；异常显示未知，不能猜测充电状态。
2. 校准采样具备缓存、离群抑制、平滑和失败恢复；初始化可重复调用，不重复占用 ADC。
3. 当前房间顶部只显示电池图标；孵化 HUD 显示百分比，低于 20% 有低电文字，未知显示 --%，不显示 0%。
4. 空存储进入真实 180 秒孵化，照料／菜单／返回可用，进度可以保存恢复。
5. 孵化按共享规则给予初始精灵和物资，触摸引导依次教喂食、互动、菜单和返回；不预设完成标记。
6. 已有档直接恢复原流程，音量 0 保持；坏档／新版本写保护不变。不清实机档来验证首次开机。

当前房间顶部时间与电池图标同一行，下方每只精灵一行显示鸡腿饱腹图标与 HP 条；
底部保留 38×38 三横线菜单入口，直接点击食盆喂食。该显示变化不修改电压端点、未知状态或保存规则。
空档孵化使用真实引擎与 HatchService，不再自动发初始精灵或预设教程完成。
保存前同步孵化进度；保存失败不得继续重启或主动关机。
