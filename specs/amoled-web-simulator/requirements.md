# 微雪 V2 网页试玩需求

依据已确认方案：`/Users/gtleaf/Documents/stickMon/微雪V2-网页模拟器方案.md`。

1. 当用户选择 StickMon × 微雪 V2 并打开试玩时，站点应懒加载真实 AMOLED 应用的 368×448 网页构建。
2. 当用户点击、拖动或取消触摸时，游戏应收到正确输入；取消手势不得变成一次点击。
3. 当用户重启或收起重开时，应恢复最近成功保存的进度；保存失败应显示提示。微雪与 Stick 存档应隔离，损坏及未来版本存档不得被默认状态覆盖。
4. 当页面隐藏或失焦时，试玩应暂停时间和声音；正常关闭面板时应先请求保存，再释放实例。
5. 当页面宽度为 320px 或 375px 时，游戏应等比显示，面板不得裁切，页面不得横向溢出。
6. 当产物缺失或目录非法时，后台应拒绝启用，公开 API 不应报告可用；新发布应保留旧资源供进行中的下载完成。
7. 当用户使用原 Stick 试玩时，原入口与存档保持兼容。

边界：仅微雪 V2 游戏试玩，不模拟 V1、真实 OTA、远程聊天和无线硬件。不发布线上环境。
