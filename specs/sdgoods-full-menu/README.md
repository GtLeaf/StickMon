# SDGOODS 圆屏菜单与页面表面

更新：2026-10-26。完整菜单已交付；当前房间 HUD 与菜单入口随后续 UI 调整同步描述。

## 行为要求

1. 当用户打开菜单时，显示探索、队伍、房间、背包、商店、电脑、设置及返回。按 2026-10-25 后续确认，移除 Save／Restart 按钮及对应菜单项，设置中的“重置游戏”保留。
2. 当用户进入入口时，可操作原共享流程及其子页：状态／技能、食物／洗澡、道具详情／确认、商品详情／购买、通讯／联系人、帮助／重置确认及重置后的孵化、有效未孵化档恢复。音频和无线已接入板级驱动，专项实机覆盖见[硬件规范](../sdgoods-hardware/README.md)。
3. 当用户点击、滑动、取消或返回时，绘制与命中使用相同坐标，页面退出不穿透；圆屏外缘不激活隐藏控件。
4. 当页面静止时按原 RenderDemand 停绘；返回房间保持既有 360×360 显示和喂食操作。
5. 当保存或重启时保持原共享快照和错误保护；旧档／高版本档／坏档不被覆盖。
6. 迁移不得引入 LVGL，保留原生字体和素材像素，复用共享玩法、资源及存档格式。OSTB／Stick 原 UI 行为保持一致。

## 设计与所有权

目的：在谷仓圆屏上操作完整离线游戏菜单，复用 OSTB 的既有流程。
视觉：沿用 OSTB 像素掌机风格、项目字体和已有图标。背景 #070c11，卡片 #18222a，描边 #384b54，强调 #73e2b7／#ffd848。

- 主房间继续直接绘制 360×360；菜单及探索／洗澡／通讯等页面使用中央 240×240 原生 RGB565 页面缓冲。独立 PSRAM 缓冲按行复制到物理帧，不缩放字体／整帧，不改 DMA 管线。
- SceneSurface 家族门面负责场景表面选择、组合和触摸坐标映射。引擎只调用门面，不包含布局数值或绘制逻辑。失败时拒绝页面输入并显示错误。
- PageProfile 显式提供页面尺寸和顶部栏安全参数；compact_touch 共享布局读取该参数。主房间／孵化的物理几何不变，跨场景成长叠层读取当前表面几何。
- 圆屏主菜单采用两列 OSTB 原图标卡片与滚动；页面顶部返回与通知复用。其余页面复用现有 compact_touch 视图和共享业务回调，窄屏弹窗单独适配。
- 存档／规则／资源载荷不变。本批迁移时音频、IMU、ESP-NOW 仍为平台桩；后续已在
  [硬件批次](../sdgoods-hardware/acceptance.md)接入真实驱动，其专项实测限制仍保留。
  首次孵化、教程和电量标准见[硬件与首次开机规范](../sdgoods-hardware/README.md)。
- 真实引擎触摸旅程覆盖全部入口及子页、保存恢复、取消／边界／失败路径，导出圆屏帧做视觉检查；既有家族像素回归、架构／调度检查及四目标构建。
- 实机只更新 OTA0 0x20000，先备份，保留设备引导层／分区表／OTA1／NVS。
