# 实现

工程 schemaVersion 保持 1，map.size 为整数范围校验（宽 16～64、高 12～64）；图层长度为宽×高。所有坐标按实际宽度寻址；旧接口默认 16×12。
前端独立 resize 模块负责预检及复制，History 包装为单步撤销。湖泊原地面索引重新映射；修改后重新修岸。
C++ 活动引擎通过仅编辑器 host 使用的编译参数指定尺寸，默认固件常量不变；Cell 类型按容量选择，防止 768 格索引截断。市集预览同步使用半格导航，正式导出保持原边界。

缩小后没有已保存道路路线引用的越界派生路网可以丢弃，避免用户擦除所有道路后仍被旧缓存阻挡。存在路线引用时仍拒绝并要求重新识别或先删除路线。

自定义尺寸路网 source 增加第四项 size；旧三项格式仅在原有两档尺寸兼容。防止相同格数、不同形状误用旧路网。画布宽或高任一变化均重设像素尺寸。64×64 的半格导航为 129×129=16641 节点，保持在共享引擎 int16_t 索引范围内。
