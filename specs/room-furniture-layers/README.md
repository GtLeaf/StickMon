# 房间与家具分层

更新：2026-10-26。保留当前资源格式、替换事务和 Debug／Release 边界。

## 行为要求

1. 当切换床或地毯时，只加载该家具资源，另一件保持选择；不预生成混搭组合。
2. 当房间首次显示、昼夜变化或配置变动时，重新合成缓存；普通帧不得重新读文件或解码。
3. 当加载失败时，保留当前房间、家具和行为数据；异常资源必须有边界及格式校验。
4. 当增加房间时，房间包携带自身尺寸、摆放、门口、活动区及行为锚点；家具通过稳定 ID 引用，可跨房间复用。
5. 当前迁移 AMOLED Debug 家具预览，保持六件详细原款和原样，保持现有玩法及存档；Release 保持正式房间。
6. 原有日夜画面、阴影、透明边缘和家具层次应保持；三目标构建和原生回归通过。

## 设计与所有权

- RoomResource：兼容 v2/v3/v4；新增 v6 分层房间（RGB565 底图、几何及 RoomFurniture 配置）。
- RoomFurniture：通用的具名摆放槽，按顺序绘制；每槽引用独立 smonfurn 透明纹理，并携带房间作者生成的日夜阴影、显隐和接收阴影属性。床与地毯只是现有两个可选槽，加载和渲染不硬编码这两种家具。
- smonfurn：版本、尺寸、压缩长度、CRC32、deflate RGB565 + alpha8，加载后展开 RGBA8888；资产不携带房间背景和位置。
- RoomRenderer：先绘制房间底图，叠加阴影，再按层次绘制家具及其接收阴影，最后转 RGB565 缓存；只在房间/家具版本或昼夜变化时合成。
- 替换纹理事务加载并校验后提交；替换房间同时替换几何、摆放与默认家具。当前 Debug 选择不落存档。
- 生成器接受布局/房间 ID，生成独立房间与家具目录；Debug 打包代替之前 15 个组合包，Release 继续使用 v4 正式图。
- 当前换款保持同一槽的尺寸、碰撞和阴影配置。将来改变家具轮廓/摆放时，应通过房间编辑器重新导出几何与投影阴影；不以贴图替换暗中改变行为位置。
