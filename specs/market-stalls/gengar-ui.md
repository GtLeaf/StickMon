# 耿鬼·秘技小屋交互与实现

日期：2026-11-07。状态：微雪 V1/V2 已接入并通过主机验证；谷仓／Stick 未接入（谷仓仍为普通对白），未刷机。

## 规则（需求5–8，用户 2026-11-06 确定）

- 一期＝一个游戏日。首次在该日打开耿鬼时，用独立种子（与 GameRandom 无关）从当前队伍中候选非空的
  队员等概率选一只，再从其候选中抽一招；记录期号、招式和抽中物种，期内不重抽，换队不变。
- 候选＝技能机兼容（Essentials Gen6 PBS `TutorMoves`，`tools/import_tutor_moves.py` 生成
  `src/game/MoveTutorData.inc`）＋升级学习表；排除基础招式、已会招式、未支持效果，以及当前已可用
  心之鳞片回忆的招式（`canRetainLevelMove`）。不设等级上限。候选全空＝本期休课。
- 价格：变化类400；威力≥86为600，61–85为400，其余200。每期只授课一次。
- 学习需健康、不太饿（饱食≥20）；替换特殊槽，熟练度归零。技能机学会的招在进化与存档清理中保留
  （`canRetainSpecialMove` 含兼容表及进化前形态），但不出现在回忆列表。
- 特训：0–39 +10/100金币，40–79 +8/200，80–99 +5/300，封顶100；每个个体每期一次，按
  ivPacked＋metAt 绑定，换队／重进／重启不重置。
- 回忆：沿用 MoveManagementService，消耗1枚心之鳞片。

## 页面（368×448，沿用变隐龙模板）

点耿鬼聊天气泡 → 双方转向 → 底框招呼（约600ms＋逐字时间后自动进入，点击可跳过）→ 菜单
（本期秘技／回忆技能／特训／离开摊位）。秘技：技能卡＋两名队员可学性 → 选替换槽（基础锁定）→
确认（熟练度与金币前后值）→ 学会页 → 回到小屋。特训：选伙伴 → 选招式 → 确认（含发动率
`BattleSystem::proficiencyTriggerChance`）。回忆：选伙伴 → 可滚动列表 → 选槽 → 确认。
上方168px为真实市集画面，镜头按交互双方抬升；子页底部按钮或点击面板外返回上一层，
首页右上“×”或点击面板外播放收起动画后结束服务。

面板外点击复用当前页已有返回流程：学习选人回首页，选槽回相应选人／回忆列表，确认回选槽／选招式，
特训选招式回选人，回忆列表回选人，结果页回首页。范围为0≤y<168的市集区域，面板内部空白不返回。
按下／抬起均须在外侧，跨边缘拖动、回忆列表滚动、锁屏取消及过渡动画中的触摸不触发；
提交期间屏蔽输入，返回确认页不扣费，返回结果页不撤销已完成的交易。招呼页沿用原点击跳过行为。

## 事务与生命周期

确认时先在实时状态上执行规则，立即 `saveState()`；失败则整体回滚并在确认页显示“保存失败”，
不扣款、不改招式、不耗额度。提交期间屏蔽重复确认。服务中摇杆／聊天冻结；锁屏取消手势保留页面。
存档 SAVE_VERSION 6 / SaveCodec schema 4 追加 `MarketTutorState`（76B 结构，编码 74B）；旧档解码为
“未开期”，坏记录在加载清理中重置为未开期。
