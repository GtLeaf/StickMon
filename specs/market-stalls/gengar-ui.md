# 耿鬼·秘技小屋交互与实现

日期：2026-11-13。状态：微雪 V1/V2 已接入并通过主机验证；谷仓／Stick 未接入（谷仓仍为普通对白），未刷机。

## 规则（需求5–8，用户 2026-11-06 确定）

- 一期＝一个游戏日。首次在该日打开耿鬼时，用独立种子（与 GameRandom 无关）从当前队伍中候选非空的
  队员等概率选一只，再从其候选中抽一招；记录期号、招式和抽中物种，期内不重抽，换队不变。
- 候选＝技能机兼容（Essentials Gen6 PBS `TutorMoves`，`tools/import_tutor_moves.py` 生成
  `src/game/MoveTutorData.inc`）＋升级学习表；排除基础招式、已会招式、未支持效果，以及当前已可用
  心之鳞片回忆的招式（`canRetainLevelMove`）。不设等级上限。候选全空＝本期休课。
- 价格：变化类400；威力≥86为600，61–85为400，其余200。每期只授课一次。
- 学习需健康、不太饿（饱食≥20）；替换特殊槽，熟练度归零。技能机学会的招在进化与存档清理中保留
  （`canRetainSpecialMove` 含兼容表及进化前形态），但不出现在回忆列表。
- 特训：0–39 +10/100金币，40–79 +8/200，80–99 +5/300，封顶100；每个个体每期一次，按
  ivPacked＋metAt 绑定，换队／重进／重启不重置。
- 回忆：沿用 MoveManagementService，消耗1枚心之鳞片。

## 页面（368×448，2026-11-13 布局）

点耿鬼聊天气泡 → 双方转向 → 底框招呼 → 用户完成一次点击 → 菜单。
招呼只播放360ms进场动画，之后持续等待，不按阅读时间自动展开；动画中点击、拖动、锁屏取消的
手势均不推进。展开420ms，关闭520ms，锁屏／熄屏暂停动画，唤醒不追赶暂停时长。

- 展开后左上“秘技小屋”、右上金币为同款浅米色圆角徽章：底色RGB(248,248,224)、字色
  RGB(40,56,80)，28px字高，金币沿用商店C符号。招呼时隐藏，随展开／关闭滑入滑出。
  此字号只用于耿鬼，其他摊位与商店不变；摊名徽章整体较首版左移5px。
- 首页移除面板内摊位名和关闭按钮，顶边从y=168下移至208，高度相应减少；三项仍为
  本期秘技／回忆技能／技能特训，每行68px，保留图标和单行名称。不可用项置灰，点击时
  在底部提示原因，约1.8秒后消失。点击面板上方市集区域退出。
- 所有服务页面顶边统一y=208，圆角14px，左右各留4px、底部留4px。子页保留返回按钮，
  切页时面板与镜头位置一致。招呼页仍为独立的底部120px对话框。
- 本期秘技保留技能图标、名称及属性／分类／威力／命中。两名精灵左右并排，卡片156×96、
  图标区80×80，不显示名字、等级或可学性文字；不可学的卡片及精灵淡化且不可选。只有一名时居中。
  回忆和特训选人页复用该布局，页标题分别为回忆技能／技能特训，不再显示伙伴副文案或次数说明。
- 忘记招式页标题固定“要忘记哪一招？”，只显示两个特殊槽，不绘制基础招式；每行只有名称与
  16px威力，无副文案及熟练度，变化招式显示“威力--”，空槽显示空位并允许直接学习。
- 教授确认页只保留技能、替换／学习正文和返回／带价格的教授按钮，不显示熟练度及金币变化。
  长正文自动换行，过长时用16px字体适配；特训、回忆确认及结果页同步适配固定高度。
- 回忆招式列表移除“名字／回忆”标题和持有数，从y=216开始，一屏3招，底部返回固定；
  超出后上下滑动、细滚动条提示位置。手势只从列表内部开始，超过阈值后捕获至松手，
  即使越过面板边缘或滑回起点也不变成点击。选槽后返回保留位置，重新选伙伴则回到顶部。
- 特训选招标题固定“要练哪一招？”，移除基础招式说明；两行均为招式名＋熟练变化小字，右侧
  显示费用，满熟练度禁选并显示已满，空槽禁选。
- 秘技：技能卡＋选择精灵 → 选替换槽 → 确认 → 学会页 → 首页。
  特训：选伙伴 → 选招式 → 确认（含发动率`BattleSystem::proficiencyTriggerChance`）。
  回忆：选伙伴 → 可滚动列表 → 选槽 → 确认。消耗和存档事务规则不改。

面板外点击复用当前页已有返回流程：学习选人回首页，选槽回相应选人／回忆列表，确认回选槽／选招式，
特训选招式回选人，回忆列表回选人，结果页回首页。所有展开页范围均为0≤y<208，
面板内部空白不返回。按下／抬起均须在外侧；跨边缘拖动、回忆列表滚动、锁屏取消、
过渡动画及提交期间均不触发，不穿透为市集行走。

## 事务与生命周期

确认时先在实时状态上执行规则，立即 `saveState()`；失败则整体回滚并在确认页显示“保存失败”，
不扣款、不改招式、不耗额度。提交期间屏蔽重复确认。服务中摇杆／聊天冻结；锁屏取消手势保留页面。
存档 SAVE_VERSION 6 / SaveCodec schema 4 追加 `MarketTutorState`（76B 结构，编码 74B）；旧档解码为
“未开期”，坏记录在加载清理中重置为未开期。
