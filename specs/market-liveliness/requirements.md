# 市集观望与混合游客方案

日期：2026-11-03。状态：已按本页实施代码；本机验证见任务清单与验收记录，尚未刷入。

## 实施前行为与问题

- 维护源为 18×17 市集，常驻为变隐龙、耿鬼、袋兽、吉利蛋。
- `MarketSession::residents()` 已有随机行走和停留，但朝向只在出生、移动或出入口穿越时更新。横向活动区中的摊主停下后仍朝左或朝右，缺少面对顾客和原地观望。
- 单只游客已实现并有完整进出／停留／暂停回归；`Family` 第二成员为 0 表示单只。当前地图候选仅有四组结伴游客，因此不会抽到单只。
- 当前全场只有一个访客会话、两个访客槽。上一组离场后再等 8～15 秒生成下一组，单只和结伴只能轮流出现。
- 游客已有在摊位附近随机停留的基础，但停留点是通用道路节点，没有明确关联摊位、顾客朝向和摊主回应。

## 预期体验

摊主在自己的摊位内走几步、停下来接待，空闲时偶尔左右张望或回身。游客三三两两进入，有的直奔摊位，有的经过时看一眼；单只与结伴能同时存在。游客与摊主会面对面交流，轮流冒出聊天气泡，偶尔兴奋地轻跳一下。不同组有独立行程，摊位之间能看到持续流动的人群。

以下参数为首版默认值，后续根据连续预览和实机表现调整。

## 摊主：走动、观望与接待

| 摊主 | 主要接待朝向 | 空闲行为 |
| --- | --- | --- |
| 耿鬼 | 向下，面对下方道路顾客 | 原两格内走动，停下看顾客；偶尔向上回身或侧看 |
| 吉利蛋 | 向下 | 三格摊位内走动，较多时间站定接待，偶尔回身 |
| 袋兽（页面名“袋龙”） | 向下 | 三格摊位内走动、停留接待和左右观望 |
| 变隐龙 | 向右，面对右侧道路顾客 | 原纵向范围内走动，停下朝道路看，偶尔回身 |

1. 当摊主完成一段行走时，应停留 3～6 秒，停留朝向与移动方向独立。空闲停留约七成时间面向接待侧，其余时间用于侧看或回身。
2. 当一次空闲观望触发时，应保持新朝向 1～2.5 秒，再恢复接待朝向；两次主动转头至少间隔 1.5 秒，避免频繁抖动。
3. 当游客在该摊位顾客点停稳，或玩家在接待侧约 1.5 格内且视线无遮挡时，摊主应在走完当前半格后面向该顾客，保持 2～5 秒。游客可相应面向摊主，形成双向回应。
4. 当多人同时靠近时，应优先回应本摊位正在浏览的组，其次回应玩家；同一目标至少保持 2 秒，避免随最近距离不断转头。
5. 当顾客离开接待范围时，应恢复空闲／走动行为。停留和转头使用已有站立方向帧；行走时继续面向移动方向。
6. 当地图维护者调整摊位朝向时，应能在工程中修改“接待朝向”和“允许观望方向”。朝向跟随 NPC／摊位配置，不按物种编号写死。

## 游客：多组同时入场

| 项目 | 首版建议 |
| --- | --- |
| 同时在场上限 | 3 组，合计最多 6 只游客 |
| 单只／结伴抽取权重 | 60%／40%，先选类别，再在类别中选候选 |
| 首组到来 | 进入市集后 2～4 秒尝试入场 |
| 后续到来 | 距上次成功入场 4～8 秒尝试补充，受组数、人数与入口空闲限制 |
| 一次逛街 | 约 45～75 秒，独立计时，包含进场、行走和停留；返程允许额外完成时间 |
| 浏览安排 | 每组浏览 2～3 个不同摊位；约 20% 的组走“经过看看”的短行程 |
| 每摊停留 | 普通浏览 4～8 秒；感兴趣时 8～12 秒 |

1. 当候选池包含单只与结伴、且容量和入口允许时，应让两类游客重叠活动；优先补充场内缺少的类别，再应用随机权重。
2. 当一组仍在场内游览时，其他组应能独立入场、选摊、停留和离开，不再等待整场上一组走完。
3. 当入口被玩家、同伴或离场游客占用时，应等待通行机会，逐只穿越入口；不能叠放、穿人或瞬移生成。
4. 当候选与刚离场的一组相同时，应降低连续重复概率；同一时刻尽量避免重复访客组合。优先补足类别属于倾向，不能因没有合适候选永久卡住补充。
5. 当使用当前四常驻、玩家和同伴配置时，六游客峰值共 12 个角色，沿用现有 16 角色预算。其他工程应校验“常驻数 + 2 + 最大游客数 ≤ 16”。
6. 当重新进入市集时，应重新建立临时访客会话，逐步入场；退出市集时释放访客活动状态。

建议先保留页面已有四组结伴候选，增加已有图包的单只信使鸟、玛力露丽、巨钳螳螂。当前四位摊主不放进首版单只池，以方便辨认。皮卡丘＋皮丘目前仍是页面配置的一组访客，本方案不擅自删除。

## 游客随机活动

- **逛摊**：优先选空闲且本次尚未访问的摊位，走到顾客点，停下并面向摊主；结束后换摊或返程。
- **观望**：在可让路的位置停 1～3 秒，看向附近摊位或左右张望，再继续行程。短暂停留不能选择入口、窄道瓶颈或顾客必经位置。
- **结伴浏览**：首位选择摊位，同行成员在同摊相邻位置停下，可独立侧看；同组保持约一格距离，避免全程机械复制朝向或分散到远处。
- **经过看看**：部分游客只短暂停一摊或沿路绕行后离开，让场内同时存在行走和浏览的角色。

当某摊位已被一组浏览时，其他组应选择其他摊位；首版每摊只接待一组。只有存在两处可达、互不重叠的顾客点时，结伴组才能选择该摊。

当顾客点已经预约时，后来者应避开该点。预约覆盖前往和停留阶段，并在换目标、离场或取消时释放，防止多个组到达同一点后互堵。

当角色被堵住时，应先等待短暂通行机会，再尝试其他顾客点或摊位。超过正常行程时长应进入返程意图并持续尝试通行；不能通过瞬移解决堵塞。玩家主动从出口离开应继续正常完成。

## 面对面聊天与轻跳演出

一次交流采用以下节奏，包含在该摊原有停留时间中，不反复延长行程：

1. **靠近站定**：游客走到预约的顾客点，等待摊主完成当前半格移动；双方停稳并面向彼此，保持约 0.5～1 秒。
2. **游客开口**：游客头顶出现现有聊天气泡，持续约 1～1.5 秒。
3. **摊主回应**：游客气泡消失，间隔约 0.2～0.5 秒，再由摊主显示气泡约 1～1.5 秒。整个交流期间保持双方朝向。
4. **偶尔轻跳**：约四成交流在其中一方开始说话时安排一次原地轻跳；每次交流最多一只跳一次，不要求双方或整组一起跳。默认抬高约 3～4 个逻辑像素，约 300ms 落回原地。
5. **继续浏览**：交流结束后继续原定浏览、观望或换摊；结伴成员可偶尔转向正在说话的一方，少量交流让同行替代领队开口，不增加整组同步动作。

- **气泡素材**：直接复用已生成的 `origin_asset/icon/market/chat.png`／`GameAssets::Kind::MARKET_CHAT`，与底部对话按钮使用同一资源。2026-11-04 按用户反馈将头顶图标由14×14放大至21×21逻辑像素（微雪1.5倍地图约32×32屏幕像素），按各精灵实际可见头顶留出约2逻辑像素间距；作为场景演出，不增加点击热区。设备与编辑器预览同步。
- **触发节奏**：约六成正常逛摊停留触发一次交流，同一组在同一摊最多一次；同一摊两次交流至少间隔 10 秒。短行程“经过看看”可只朝摊主停一下，不强制聊天。交流次数、轻跳与行程使用独立随机序列。
- **全场上限**：最多两个摊位同时交流，每摊同一时刻仅一方显示气泡，避免全场同时冒泡。没有演出名额时继续浏览或在本次停留内稍后尝试，不为演出占住摊位额外等候。
- **画面与遮挡**：跳跃只改变精灵绘制高度，影子留在地面；导航脚底、碰撞、顾客点预约和地面深度排序均不变。气泡跟随角色头顶、跳跃与镜头，使用实际精灵尺寸定位，遵守场景遮挡、地图视窗和圆屏裁切；气泡不为避让而改变角色位置。
- **中断与恢复**：移动中不触发跳跃；暂停／锁屏时冻结气泡、跳跃和交流计时，恢复后继续。换目标、进入返程、退出地图或交流对象失效时立即取消演出、清除气泡和高度偏移，并释放交流占用。玩家走出出口不受演出阻挡。
- **行为边界**：首版为氛围交流，不增加对白文本、交易结果或新对话面板；底部玩家对话入口的业务另行设计。

## 工程配置与共享约束

- NPC 配置增加接待朝向、允许观望方向与停留节奏；旧工程缺省时保留原行为，当前市集显式启用新行为。
- 游客配置区分候选池与并发组数，增加单只／结伴权重、入场间隔和行程时长；当前单组运行模式可继续使用。
- 摊位配置关联常驻 NPC、顾客停留点及可供结伴停留的相邻点。顾客点先由邻近道路产生候选，再在编辑器核对；不用与摊主相同的活动格充当顾客点。
- 在 `Market::Session` 中统一实现各组独立状态、朝向、预约及交流时间线，绘制层消费气泡归属与跳跃进度。编辑器活动预览、正式绘制预览和各设备复用同一核心，工程导出与预览传输格式一起升级。
- 随机决策和寻路按组错开，沿用 100ms 模拟步长；跳跃绘制按会话时间平滑取样。区分转头、演出与行程随机数，避免仅增加观望或气泡就扰动整场游客行程。
- 使用已有方向素材和现有图包预算。保留本次 18×17 地图的图层、物件位置、道路和摊主活动范围；新增行为只影响市集临时会话，存档与探索业务语义保持。

## 验收条件

1. 在连续 60 秒预览中，耿鬼、吉利蛋和袋兽均能看到向下站定；变隐龙能向右站定；可看到至少一次侧看或回身，行走和原地观望能明显区分。
2. 在“单只＋结伴”候选和畅通入口的固定种子用例中，必须出现单只组与结伴组同时活动，并验证 3 组并发、6 游客峰值上限。
3. 在至少两个摊位同时有游客浏览时，游客应朝向各自摊位，摊主应回应自己的顾客；目标保持期间不能每 100ms 换向。
4. 在长时间、多种子模拟中，角色不能占用相同起点或终点、走出各自允许网格、使用精灵 0 或遗留已结束组的预约；每组应能完成进出。
5. 在入口对向会车、摊位满员、玩家挡路、同伴跟随和走出返回用例中，应能等候、改选目标并恢复通行；禁止通过移除碰撞或瞬移通过测试。
6. 当暂停或锁屏时，移动、转头、停留、入场和交流演出计时都应冻结；恢复后不追补时间。重新进图不残留旧组、气泡或跳跃偏移。
7. 当前 18×17 与其他合法尺寸的编辑器预览、固件模拟应一致，旧单组／单只工程继续通过回归。
8. 交付连续 60～90 秒的正式绘制器预览，重点展示混合入场、双向接待、轮流气泡、偶尔轻跳和错峰离场；静态截图不足以验收活动节奏。
9. 完成市集、资源、三家族场景回归及受影响目标构建，并检查谷仓应用体积、导航栈、资源缓存和实际帧耗时；真机显示、触摸与性能单独记录实测结果。
10. 在固定种子交流用例中，应看到游客与摊主轮流使用现有气泡、至少一次轻跳及结伴成员回应；单摊同时最多一个气泡，全场最多两摊交流。轻跳前后地面位置、预约和排序依据保持一致，落地不偏移，影子不随身体升高。
11. 对不同体型精灵、镜头边缘、摊棚遮挡及圆屏边缘进行绘制检查，气泡应跟随实际头顶且无越界绘制；交流途中暂停、目标取消和玩家离场时，不能留下悬空气泡、跳跃偏移或演出占用。
