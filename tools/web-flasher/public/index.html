刷机步骤
  1. 用 USB 数据线把 StickS3 连接到电脑（充电-only 线不行）
  2. 在下方选择版本，点 一键刷入 → Connect，在弹窗中选择设备串口
  3. 等待 1~2 分钟写入完成，设备自动重启
  4. 若连接失败 / 设备变砖：按住机身 BOOT 键不放，再插拔一次 USB，松开后重试 Connect
  5. 刷机不会清除设备里的存档与设置（NVS 分区保留）
