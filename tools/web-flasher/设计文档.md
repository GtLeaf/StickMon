# StickMon Web Flasher · 设计文档 v1.0

> 位置：`tools/web-flasher/`
> 目标：面向终端用户的固件分发站。用户用 USB 连接电脑后，在浏览器里一键把固件 + LittleFS 数据刷入自己的 StickS3（ESP32-S3）；管理员在 Web 后台上传/编辑/删除固件版本。

## 1. 需求映射

| # | 需求 | 实现 |
|---|------|------|
| 1 | 权限控制，仅管理员可增删改查 | scrypt 口令哈希 + httpOnly 会话 Cookie；所有 `/api/admin/*` 路由经 `requireAdmin` 守卫（会话校验 + 自定义头 CSRF 防护） |
| 2 | 任何人都可刷固件，但要频控防流量攻击 | 三级频控：通用 API 120 次/分/IP；下载通道 30 次/10 分钟/IP；每 IP 每日 200MB 流量配额（可配） |
| 3 | 简洁上传页，新固件号自动填入且可修改 | `/admin` 上传表单；`GET /api/admin/next-version` 按最新版本 semver patch+1 自动预填，可手改 |
| 4 | 主页图片展示各版本，一键刷入 | 主页卡片画廊（封面图 + 版本 + 说明 + 刷机次数），每卡内嵌 `esp-web-install-button`，指向服务端动态生成的 manifest |
| 5 | 首页轮播图，管理员可更换 | `slides` 表 + `seed_slides/` 初始播种；管理后台支持上传（多选）/ 删除 / 上移下移排序 |

## 2. 总体架构

```
┌─────────────┐   HTTPS    ┌──────────────────────────────┐
│  用户浏览器  │ ─────────► │  Node.js (Express)           │
│             │            │  ├─ 静态页 /assets, /, /admin │
│ esp-web-    │  WebSerial │  ├─ 公开 API (列表/manifest/  │
│ tools       │ ◄────────► │  │   bin 下载) [频控+流量闸]  │
│ (esptool-js)│   USB      │  ├─ 管理 API (CRUD) [会话守卫]│
└──────┬──────┘            │  └─ node:sqlite (flasher.db)  │
       │                   └──────────┬───────────────────┘
       │ 串口写入 flash               │ 文件系统
       ▼                              ▼
┌─────────────┐               data/firmware/<id>/*.bin
│   StickS3   │               data/images/<id>.<ext>
└─────────────┘
```

刷机数据流：浏览器拉取 manifest → 按 manifest 里的偏移逐个下载 bin → esptool-js 通过 WebSerial 写入设备 flash。**固件字节不经过任何第三方服务器**，本站只承担分发。

## 3. 技术选型

| 层 | 选型 | 理由 |
|---|------|------|
| 后端 | Node.js ≥ 22.5 + Express 4 | 部署普遍，无构建步骤 |
| 数据库 | `node:sqlite`（Node 内置） | 零原生依赖，`npm install` 只有 express + multer 两个包 |
| 上传 | multer 2.x（diskStorage） | 多文件 multipart，落盘临时目录再校验搬运 |
| 刷机前端 | esp-web-tools 10（unpkg CDN） | ESPHome 出品，封装 esptool-js，自带连接/烧录/进度 UI |
| 会话 | 随机 32B token + SQLite sessions 表 | 不引入 redis 等外部组件 |
| 口令 | `crypto.scryptSync`（内置） | 无 bcrypt 原生依赖 |

## 5. 数据模型

### firmwares 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | UUID |
| name | TEXT | 固件名称（≤64 字符） |
| version | TEXT | 版本号（≤32 字符） |
| notes | TEXT | 更新说明（≤2000 字符） |
| image | TEXT NULL | 封面图文件名 |
| files | TEXT(JSON) | `[{key, file, offset, size, sha256}]` |
| chip | TEXT | 固定 `ESP32-S3`（预留多机型） |
| downloads | INTEGER | 刷机次数（按 manifest 拉取计） |
| created_at / updated_at | INTEGER | 毫秒时间戳 |

### files JSON 示例

```json
[
  {"key":"bootloader","file":"bootloader.bin","offset":0,"size":21504,"sha256":"…"},
  {"key":"partitions","file":"partitions.bin","offset":32768,"size":3072,"sha256":"…"},
  {"key":"boot_app0","file":"boot_app0.bin","offset":57344,"size":8192,"sha256":"…"},
  {"key":"firmware","file":"firmware.bin","offset":65536,"size":1458176,"sha256":"…"},
  {"key":"littlefs","file":"littlefs.bin","offset":4521984,"size":983040,"sha256":"…"}
]
```

## 6. 烧录偏移（ESP32-S3）

| 文件 | 默认偏移 | 来源 |
|------|---------|------|
| bootloader.bin | `0x0` | ESP32-S3 固定（注意与 ESP32 的 0x1000 不同） |
| partitions.bin | `0x8000` | 固定 |
| boot_app0.bin | `0xe000` | Arduino 框架固定 |
| firmware.bin | `0x10000` | app 分区起始 |
| littlefs.bin | `0x450000` | **与 StickMon 工程 `partitions_stickmon_8mb.csv` 一致**（8MB 布局：app0/app1 各 0x220000，littlefs 0x3A0000 @ 0x450000），上传表单中仍可改 |

⚠️ 若分区表调整，务必同步修改上传表单中的偏移。偏移错误会覆盖相邻分区导致变砖（可用 BOOT 键进下载模式恢复）。

## 7. API 一览

### 公开

| 方法 | 路径 | 频控 | 说明 |
|------|------|------|------|
| GET | `/api/firmwares` | 120/min | 固件列表（不含 bin 内容） |
| GET | `/api/firmwares/:id/image` | 120/min | 封面图 |
| GET | `/api/slides` | 120/min | 首页轮播图列表（按 sort 排序） |
| GET | `/api/slides/:id/image` | 120/min | 轮播图片 |
| GET | `/api/firmwares/:id/manifest.json` | 30/10min + 流量闸 | esp-web-tools manifest，拉取即记一次刷机 |
| GET | `/files/:id/:filename` | 30/10min + 流量闸 | bin 下载，响应头带 `X-Content-SHA256` |
| POST | `/api/login` | 10 次/10min | 管理员登录 |
| POST | `/api/logout` | — | 登出 |
| GET | `/api/me` | — | 会话状态 |

### 管理（均需会话 + `X-Requested-With: fetch` 头）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/next-version` | 下一建议版本号（最新 semver patch+1，无记录则 `0.1.0`） |
| POST | `/api/admin/firmwares` | multipart 上传：5 个 bin（firmware 必选）+ 可选 image + name/version/notes + 每文件 `offset_<key>` |
| PUT | `/api/admin/firmwares/:id` | JSON 修改 name/version/notes |
| DELETE | `/api/admin/firmwares/:id` | 删除记录并清理磁盘文件 |
| POST | `/api/admin/slides` | multipart 上传轮播图（字段 `images`，一次 ≤6 张，PNG/JPEG/WebP ≤5MB，MIME+魔数校验） |
| DELETE | `/api/admin/slides/:id` | 删除轮播图并清理文件 |
| PUT | `/api/admin/slides/:id/move` | 调整顺序，body `{dir: -1 \| 1}`（与相邻项交换） |

### manifest 输出示例（esp-web-tools 规范）

```json
{
  "name": "StickMon 电子宠物机",
  "version": "0.1.0",
  "new_install_prompt_erase": false,
  "builds": [{
    "chipFamily": "ESP32-S3",
    "parts": [
      {"path": "/files/<id>/bootloader.bin", "offset": 0},
      {"path": "/files/<id>/littlefs.bin",   "offset": 4521984}
    ]
  }]
}
```

`new_install_prompt_erase: false` → 默认不清全片，**NVS（存档/设置）在刷机后保留**。

## 8. 安全设计

| 威胁 | 对策 |
|------|------|
| 口令暴力破解 | 登录 10 次/10min/IP；scrypt 哈希 + timingSafeEqual 比对 |
| CSRF | Cookie `SameSite=Strict` + 管理写操作强制自定义头 `X-Requested-With: fetch`（表单无法伪造） |
| 会话窃取 | httpOnly Cookie；生产环境（`NODE_ENV=production`）自动加 `Secure`；12h 过期；SQLite 定期清理 |
| 路径穿越 | 下载按 DB 记录的 file 名精确匹配，再 `startsWith` 校验落盘路径 |
| 恶意上传 | bin 限 `.bin` ≤ 20MB/个；封面图限 PNG/JPEG/WebP ≤ 5MB，**MIME + 魔数双重校验** |
| 流量攻击 | 下载 30 次/10min/IP + 每 IP 每日 200MB 配额（`DAILY_DOWNLOAD_MB` 可调）+ 页面/通用 API 120 次/分 |
| 信息泄露 | 关闭 `X-Powered-By`；`nosniff` / `X-Frame-Options: DENY` / `Referrer-Policy: same-origin` |
| 注入 | 全部 SQL 走参数化预编译语句 |

## 9. 频控参数速查

| 通道 | 窗口 | 阈值 | 备注 |
|------|------|------|------|
| 登录 | 10 min | 10 次/IP | 防爆破 |
| bin/manifest 下载 | 10 min | 30 次/IP | 一次完整刷机 = 1 manifest + ≤6 文件 |
| 每日流量 | 自然日 | 200MB/IP | `DAILY_DOWNLOAD_MB` 环境变量 |
| 通用 API/页面 | 1 min | 120 次/IP | — |

实现为内存滑动窗口（单进程部署足够）；重启后计数清零属可接受语义。多实例部署需换 redis 等共享存储。

## 10. 配置项（环境变量）

| 变量 | 默认 | 说明 |
|------|------|------|
| `PORT` | `7100` | 监听端口 |
| `DATA_DIR` | `./data` | 数据目录（db + bin + 图） |
| `ADMIN_PASSWORD` | 无 | **首次启动**注入则作为管理员口令；未设置则生成随机口令打印一次 |
| `DAILY_DOWNLOAD_MB` | `200` | 每 IP 每日下载配额 |
| `TRUST_PROXY` | 无 | 置 `1`：反代（Nginx/Caddy）后取真实客户端 IP，否则频控全打在反代 IP 上 |
| `NODE_ENV` | — | `production` 时 Cookie 加 `Secure` |

## 11. 部署（要点）

WebSerial 强制要求 HTTPS（localhost 除外），生产必须套 TLS：

1. 服务器装 Node ≥ 22.5 → `npm install` → `ADMIN_PASSWORD=xxx PORT=7100 TRUST_PROXY=1 npm start`
2. Caddy 反代（最省事，自动签证书）：
   ```
   flash.example.com {
     reverse_proxy 127.0.0.1:7100
   }
   ```
3. systemd 常驻 + `DATA_DIR` 定期备份（bin + db 即全部状态）
4. esp-web-tools 目前从 unpkg CDN 加载；内网/离线部署需把 `install-button.js` 下载到 `public/assets/` 并改 index.html 引用

详细步骤见 [README.md](README.md)。

## 12. 首页轮播图

- 数据：`slides` 表（id / file / sort / created_at），图片存 `data/slides/`
- 初始图：`seed_slides/` 目录随项目分发，**首次启动且 slides 表为空时**自动导入（当前内置 3 张压缩后的产品图，1600px / ~90KB 每张）
- 主页：21:9 轮播组件，5 秒自动切换，支持左右箭头、圆点导航、悬停暂停；无图时整个模块隐藏
- 管理：`/admin` 新增「首页轮播图」面板，支持多选上传、上移/下移排序、删除（连带清理文件）
