# StickMon 地图工坊

本地浏览器地图编辑器：原素材浏览、自定义尺寸三层地图（最小 16×12）、完整物件、路线、保存/重开、游戏数据编译和正式绘制器预览。

## 启动

在 Finder 双击本目录 `start.command`，或在项目根目录执行：

```sh
tools/map_editor/start.command
```

默认打开 http://127.0.0.1:8767 。首次启动在 `.stick-local/venvs/map-editor/` 创建独立 Python 环境并安装 Pillow。需要 Python 3 和可用的 C++17 编译器（macOS Command Line Tools）。也可使用已有 Python：

```sh
MAP_EDITOR_PYTHON=/path/to/python tools/map_editor/start.command --port 8768
```

Essentials 根目录通过 `ESSENTIALS_DIR` 配置，或使用 `external/pokemon-essentials`；目录应包含 `Graphics`。不在工程文件中保存个人绝对路径。运行时别名素材还会读取项目中已有河谷参考原图和资源包。

## 推荐工作流

1. 点击“导入地图”，选择地区、种子、入口与段号；或从空白地图开始。
2. “完整物件”选择树、遮棚、花箱、桌子等，在地图上单击放置。
3. 按 M 框住多个完整物件，松手后拖动其中任意物件即可整体移动；也可用选择工具 Shift 多选。右侧可改位置、落地点和占地。旧森林中可恢复的同深度树片已成为树木/树群。
4. 精修时选择“拆成图块”，再用笔刷、填充、吸管；也可以使用“图块框选”后“存为组合”。原图块页支持整张图集展开、矩形取样，不只显示顶部素材。
5. 铺好双格道路后，点击“识别道路”，再点“存为路线”，自动生成一条走遍路网并返回起点的路线，同时保存工程。可直接“播放”预览。手工行进路线仍可单击转折点补齐逐格路径，洞穴可改用格心路线。
6. 打开预览精灵并播放；切换 32px 原图或 26px 逻辑图。浏览器画面为遮挡示意。
7. “校验地图”定位错误；草稿可以保存，错误地图不能编译。
8. 保存工程到本机，或“导出 → 下载工程 JSON”。正式绘制器预览会生成实际资源全图和 AMOLED 逐点路线画面 ZIP；首次可能需要编译本机绘制程序。

快捷键：V 选择，B 放置，P 笔刷，E 擦除，F 填充，I 吸管，M 框选，R 路线，W 自动铺湖；空格拖动画布；Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 重做，Cmd/Ctrl+S 保存，Cmd/Ctrl+D 复制物件，Cmd/Ctrl+C/V 复制/放置选区。

## 框选与整体移动

点击“框选”或按 M，拖出覆盖完整物件的矩形，松手后自动回到选择工具。拖动任意选中物件，整组按同一偏移移动，保持相对位置；触及地图边缘时整组停下。一次拖动只产生一次撤销，Esc 取消当前拖动。

- 仅选中完全框入的完整物件；隐藏、涉及锁定图层或被完全覆盖的物件不加入。地面笔刷图块、NPC 和活动区域不随物件移动。
- Shift 开始框选可以追加；选择工具仍支持 Shift 单击增减。空选框清除选择；单击选中物件不会改变覆盖顺序，实际移动后才置顶。
- 原来的矩形图块复制功能保留在“图块框选”，可复制、存为组合；不能直接移动原始图块。

## 属性面板与尺寸帮助

右侧六个模块都可以点击标题独立收起／展开，并在当前浏览器记住状态。首次使用时「图层」「当前选中」展开，其他模块收起。选择新物件会展开「当前选中」；选择路线、区域或 NPC 工具会展开对应模块。

「地图尺寸」标题旁的 `?` 集中显示尺寸范围、扩展／缩小规则、出入口与导出限制；点问号不会改变模块的展开状态。可用键盘 Enter／空格打开，点击外部或按 Esc 关闭；关闭帮助不改变当前地图工具。

## 自动铺湖

在“完整物件 → 湖泊”选择“自动铺湖”（W），自动切到地面层 L0。

- 单击远离水域的空地，生成 3×3 小湖；靠近已有水域时只增加当前格。拖动逐格扩展，自动连接相邻水域。
- 根据八个相邻格匹配湖岸、外角、凹角、孤立水塘和窄水道；在湖中退水可形成岛洞。
- “退水”或按住 Shift 开始笔触逐格移除水域，并恢复铺湖前的地面；每次拖动可以整体撤销或重做。普通 L0 擦除也识别水域。
- 相连的旧湖泊组合会在编辑时转成自动水域，保留原地面；旧的独立水面图块若没有原地面记录，退水恢复默认草地。不会覆盖未拆分的非水域完整地面物件；锁定 L0 后不能铺湖或退水。
- 工程用可选 `map.lakeGround` 字典保存每格的原地面；导出仍使用普通 L0 图块，游戏无需运行自动铺岸算法。路线经过水域仍需桥面。
- 自动湖泊使用 Essentials 原 Sea 图集四分块，47 种形状各 8 帧动画。底岸沿用现有河谷的纵向翻转方式；未重绘素材。

## 原图矩形取样与透明背景

原图透明区域会完整保留。当前选中 L0 时，含透明区域的取样自动放到 L1 物体层，保留下方原地面；完全不透明的地面取样仍使用 L0，已选 L1／L2 时沿用所选层，素材自身要求的图层优先。

早期取样若放在 L0，会整格替换地面，让透明处露出画布黑底。打开工程时会自动修正仍采用原取样几何的此类组合，并同步原生占地；自定义锚点或占地的组合保留原定义。此操作保持原像素和颜色，不会将物件自身的黑色轮廓或阴影抠除。

## 精选素材与道路地面

- 素材库分为“精选素材”和“原图块”。精选素材按固定顺序分成道路地面、湖泊、自然景物、集市、围栏设施；空分类不显示。
- 每张精选素材卡片右上角有“×”：从当前工程素材库移除，可撤销／重做；保存工程后保留删除结果。内置素材及地图正在使用的组合保留定义，只从素材库隐藏，不影响已放置物品、道路和导出；未使用的自定义组合直接移除。原图块与其他工程不受影响。
- 树木、草花、岩石并入自然景物；货车并入集市；石围栏、梯子并入围栏设施。导入物件与自定义组合在有内容时显示为“自定义组合”；用户自行命名的其他分类保留。旧工程只更新素材库分组显示，不改写已放置物件的定义。
- 道路地面提供 13 种现有游戏土路图块：路面、四边、四个外角、四个内凹角，以及 5 种草地。名称标清方向，搜索也支持图块编号。
- 点击道路／草地卡片会切到 L0 地面笔刷，可单击、拖动连续铺设、替换和撤销，不创建完整物件，因此无需先拆分道路。完整物件和锁定图层仍受保护；手铺道路不会自动添加角色行进路线。
- “识别道路”替代原铺路按钮，只读取现有双格道路并生成无方向路网，保留环路、路口和支路，避开物件占地。青色为道路中线，琥珀色框标记未接入的窄路或被遮挡道路；“显示路网、路线与入口”控制显示。识别可撤销，工程 JSON 保留 `map.roadNetwork`；改动图层、物件或组合后隐藏旧结果并提示重新识别。
- “存为路线”从最靠近地图入口的路网点出发，逐段遍历并折返，覆盖所有路段后返回起点；不跨越不连通道路。生成结果加入 `paths`（`kind=roadNetwork`，道路中线坐标），允许重复经过相同位置，最多 1025 点。重复操作更新同一条道路路线，保留其他手工路线；已有三条手工路线时提示先删除一条。操作可撤销，并直接保存整个当前工程；保存失败保留编辑结果以便重试。此类路线支持编辑器播放与工程 JSON 保存；游戏 ZIP 导出为独立市集导航包，正式预览使用市集会话。不会塞入普通探索 Path。旧探索路线仍使用原有坐标及校验规则。
- 湖泊按钮仅在湖泊分类显示；离开湖泊分类或切换到原图块会退出铺湖／退水模式。

## 箱子透明叠放

两／三层木货箱和标签货箱的上半部使用 L2 前景、下半部使用 L1 物体，透明留白会露出后方货车等 L1 内容，预览、PNG 和固件导出一致。两个部分共用箱底遮挡深度；碰撞仍只有底部一格。操作此类箱子需要 L1、L2 都未锁定。

旧工程中原版堆叠箱会在打开时自动更新图层，保留名称、位置、锚点和层数；已修改几何的自定义组合保持原定义。组合定义更新后，旧路网可能提示需要重新识别道路并存为路线。

## 集市物件旋转

首批开放六种物件：格纹长桌、条纹长桌、花苗长箱、木货箱、绿条纹躺椅、蓝条纹躺椅。素材卡片标有“可旋转”；在放置模式旋转待放置物件，在选择模式旋转单个已放置物件。

花苗长箱现为 2×1 格（旋转 90°/270° 为 1×2）：从原 3×2 素材裁去 16px 留白，保留完整原像素，不缩放。新放置使用紧凑版；旧工程中已放置的 3×2 版本保留原位置和外观，可删除后从素材库重新放置紧凑版。

蓝、绿条纹躺椅现为 1×2 格（旋转 90°/270° 为 2×1）：从原 1×3 素材去掉上下各 16px 的透明留白，完整保留椅背、坐面和椅脚，不缩放。旧版 1×3 实例保持兼容，新增放置使用紧凑版；碰撞和遮挡随新尺寸计算。

- 画布上方的 `↶ 90°` / `↷ 90°` 按钮，或 `[` / `]` 快捷键，切换 0°、90°、180°、270°。`R` 仍为路线。
- 旋转保留左上角所在格，自动交换宽高，重新匹配当前朝向的落地点、占地和游戏遮挡。越界时拒绝整次旋转；锁定物体层时不可旋转。放置、移动和旋转默认覆盖同层同格的旧内容，后操作的物件位于上方，不再要求先移到空处。
- 放置前的预览和卡片同步显示当前方向，连续放置保持方向。放置后旋转可撤销／重做；复制、工程保存重开和导出保留方向。单个支持旋转的物件用 Cmd/Ctrl+C/V 复制后仍能旋转。
- 使用经过检查的原像素 90° 变换，没有插值或重绘。现有三款遮棚经四向对照后暂不开放：棚柱会横躺或倒置。围栏、花丛等其他类别留待后续。
- 不同图层仍按 L0 地面、L1 物体、L2 前景叠放；同层以实例顺序决定每格最终内容，重叠不再是校验错误。被覆盖的旧物件保留在下方，删除上方物件可露出旧内容；覆盖和置顶均随撤销／重做恢复。碰撞占地、NPC 寻路和导出使用最终可见的格子，不保留被盖住部位的碰撞。
- 旋转变体保存在组合引用中，不修改原组合；旧工程不含变体时按需追加。自定义过锚点、占地或组成图块的物件不自动替换为标准旋转版本。

## 木货箱与标签货箱堆叠

放置并选中「木货箱」或「标签货箱」，在右侧「当前选中 → 堆叠层数」选择 1、2、3，默认 1。切换保持箱底的地面位置，向上增加箱身；底部仍只占 1 格，NPC 可以从上部箱身后方通过，遮挡沿用完整物件的地面锚点。2／3 层的图块范围是 1×2，2 层顶部含透明留白，不会拉伸原像素。

- 仅原始两种箱子支持；编辑过锚点、占地或图块的自定义组合不会自动替换。增加堆叠前，已旋转的木货箱需先恢复 0°；2／3 层暂不旋转。
- 锁定物体层后不能切换层数。靠地图顶边且上方空间不足时会提示先下移箱子，整次操作保持原样。
- 切换支持撤销／重做；复制、保存重开、工程 JSON 和设备数据包保留层数。覆盖逻辑与其他完整物件一致。
- 复用绿宝石货箱顶面与箱身原图，追加 8 个稳定图块（13099～13106）；旧图块和 Kind 编号保持。使用新增堆叠的设备地图需同步更新固件与地图资源包。

## 活动区域与 NPC

- 画布工具新增“区域”和“NPC”；点击后自动展开右侧“活动区域与 NPC”。区域和 NPC 各最多 16 个，使用稳定 ID 独立于图层保存，旧工程无需迁移。
- 新增区域后用矩形圈选，或涂抹添加／擦除范围；可重叠，区域名称和颜色可调整。删除仍被 NPC 使用的区域时会提示先调整活动范围。
- 新增 NPC 后单击地图设置出生点，NPC 工具可拖动位置。“精灵”可选择项目现有的 64 种宝可梦，默认皮卡丘；复用游戏资源包的四向待机／行走帧、实际帧尺寸和脚底锚点。右向缺帧的精灵按游戏素材规则镜像左向。旧工程的人物外观保留读取与导出，新建 NPC 不再提供人物选项。配置原地停留、随机散步或沿点巡逻；巡逻最多 32 个点，自动在通路中寻路。
- NPC 可选择多个区域的并集，或全地图自由活动。水域、完整物件占地和原图块阻挡会被排除；未知地面语义保守阻挡。出生点重复、无法活动、巡逻点或绑定区域不可达会阻止活动预览与游戏源数据导出。不同连通片有提示。
- 连通片提示会列出各片的格坐标（从 0 开始），可擦除误选的零散格子或补齐通行范围；区域外即使有路，绑定该区域的 NPC 也不会越界绕行。“沿点巡逻”需要至少两个不同的巡逻点，出生点不会自动成为巡逻点；不需要固定路线时改为“随机散步”。
- “检查活动配置”独立于探险路线校验；尚未绘制玩家路线也可以预览 NPC。“预览活动”运行 120 秒，可暂停、继续和重置。编辑地图会废弃旧预览，预览不写回出生点；播放期间编辑会回到配置姿态。
- 区域内可开启“随机结伴来访”，搜索并勾选候选组合，无需新增 NPC 或设置出生点。目前从游戏进化链与现有精灵资源提取 38 组“进化型＋最初幼体”（包括伊布各分支），排除神兽、幻兽和人物；未进化精灵或缺少同链资源的物种不单独混搭。默认皮卡丘＋皮丘，可同时选择多组，等概率抽取。
- 来访组合从地图已有的边缘入口／路线出口中选择可达入口，依次从画面外走入、结伴到达区域的相邻两格、待机停留，再倒转队列原路离开。市集使用底部中央已标记的入口，不从其他边缘空地随机出生。到达后停留与离开后间隔均可设置 1～60 秒的随机范围；每区最多一组，多区域错峰进出，共用通道时会等待。候选区域至少要有两个相邻可通行格，零散区域、堵塞入口或无法到达会阻止预览。
- 随机区域最多 8 个；每个区域预留两只，与固定 NPC 合计最多 16 只。固定 NPC 独立保留，若希望随机组合替代原 NPC，请删除对应固定 NPC。旧 NPC 配置错误仍需处理，例如沿点巡逻至少设置两个点。待机的固定 NPC 会作为来访寻路的障碍，其他精灵共用格子预约以避免重叠。
- “暂停／继续”沿用本次随机结果；“重置预览”后重新开始会重新抽取，不写回候选池或固定出生点。随机来访的时间轴同样由共享 `src/game/AuthoredNpcPopulation.h` 生成，浏览器只插值和绘制。
- 浏览器通过本机 C++ 核心生成时间轴，以同一个 `src/game/AuthoredNpc.h` 计算散步、巡逻和 NPC 目标格预约。没有第二套 JavaScript 行为算法；暂停不会改变源数据。
- 工程 JSON 保留 activityZones/npcs。游戏数据包额外包含 activity.json、AuthoredNpcs.h、AuthoredNpc.h、使用的精灵 PNG 图集、原始 `.smonsp` 资源包和来源哈希；npc-sources.json 记录物种编号、四向动画帧与脚底锚点。现有自定义地图尚需在设备场景中显式接入加载入口及精灵绘制，未自动修改正式地图、存档或刷机。普通 PNG 和“正式绘制器预览”仍是地图背景/玩家路线预览，NPC 效果使用“预览活动”。
- 随机规则保存在 `activityZones[].visitors`；经典地图导出的 activity.json 为 version 2，另含 AuthoredPopulations.h、AuthoredNpcPopulation.h、npc-families.json 和所有启用候选组合的素材，不冻结为本次预览抽到的两只。道路市集使用下文独立导航包和 `Market::Session`，不使用经典人口会话。
- 不含对话、交易、日程或跨地图 NPC。道路市集已接入玩家与 NPC 的统一格子预约；经典预览不包含玩家。实机同时活动容量仍待测量，编辑器的 16 个配置上限不是实机性能承诺。

## 保存与导出

- 本机工程：`.stick-local/map-editor/projects/*.stickmap.json`，临时写入后原子替换。
- 浏览器自动备份：通过“打开 → 恢复浏览器草稿”，不是唯一保存副本。
- 可移植工程保留素材键、来源哈希、组合定义、实例、路线与生成上下文；原素材需另行配置。
- 游戏 ZIP 包含 `AuthoredMap.h`、`runtime-map.json`、`resource-requirements.json`、工程源、PNG 和验证报告。C++/Python 指纹及路径点校验通过才输出。
- `AuthoredMap::load()` 返回现有 `ExploreMapGenerator::Map`，待明确地图选择条件后接入正式流程。编辑器不会自动改变正式地图或刷机。

- 更新工具后，旧工程若提示来源哈希变化，请先核对预览，再点“核对后更新来源记录”。已有物件定义不会被新版组合覆盖。

## 调整地图大小（2026-11-02）

在右侧「地图与属性 → 地图尺寸」分别填写宽和高，点击「调整尺寸」。宽度 16～64 格，高度 12～64 格，必须是整数，不要求固定比例。例如 25×18、40×30 或 64×64；原 16×12、32×24 工程直接兼容。扩展保留左上角的所有原坐标，新增区域填草地；支持单步撤销／重做，调整后保存工程。旧工程直接兼容。

右／下边界入口、普通出口随边界移动，原道路与路线点不自动延长。扩展后请接好新边界道路，再「识别道路 → 存为路线」。原识别结果保留为过期状态，避免误当作最新路网。缩小时会检查地形、物件、活动范围、NPC、巡逻点、路线和出入口，边界外有内容就拒绝并列出原因；不会自动删除内容。

自定义尺寸支持编辑、旋转、湖泊自动修岸、道路识别与播放、区域／精灵／随机访客预览、保存工程、JSON 和 PNG。原素材 PNG 的宽高为地图格数各乘 32，例如 40×30 导出 1280×960。NPC 预览仍调用共享 C++ 引擎，编辑器专用尺寸参数与宽索引不改变设备默认 16×12 布局。设备包和正式绘制器导出暂限 16×12，大地图会明确拒绝。

新增回归：`.stick-local/venvs/map-editor/bin/python tools/test_map_editor_size.py`、`node tools/map_editor/test_size.mjs`。测试工程只使用临时目录，不写入用户地图列表。

2026-11-03 市集设备导出已支持当前 18×17 工程，普通探索仍保持 16×12。市集图层、常驻出生／巡逻索引、半格导航、镜头和遮挡均按市集自身尺寸处理；`MarketMapData.h` 与 `MarketMapSize.h` 必须一起生成和安装。设备导出暂限 1295 个导航点以控制 16 KiB 主任务栈的搜索开销，更大的地图仍可编辑和预览活动。完整绘制器预览独立链接正式渲染与资源代码，可预览与已安装地图尺寸不同的工程。

刷入用户编辑的新地图前，先从用户当前编辑器页面下载工程并与维护源核对尺寸、常驻名单和画面；浏览器草稿不会自动覆盖仓库维护源。不要把旧维护源重新编译称为已更新浏览器地图。
