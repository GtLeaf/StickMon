## 结论

原图宽 1565–1798 像素，远大于房间需要。库内使用预先 LANCZOS 降采样的 RGBA 副本：地毯 204×100、床铺 160×102，对应逻辑尺寸 102×50、80×51。六张 PNG 总体积从 11,235,140 字节降到 239,926 字节。此数字是编辑器 PNG 文件大小，不代表固件房间包或运行帧率的变化。

原图直接最近邻缩小会令细纹理和轮廓碎裂，预先降采样改善明显。可是家具仍偏细腻插画，和粗像素精灵的颗粒不统一。下一版应在实际逻辑尺寸定稿，减少编织纹理、细碎阴影和小装饰，放大叶片/月亮/云朵的主体图案，再用整数 2× 输出微雪资源。森林款最融入现有绿色木屋，星月款轮廓辨识度高，白云地毯在小尺寸下的云朵主题较弱。

此次只增加素材库和独立预览，没有替换正式游戏资源，也未刷入设备。库内床铺沿用原床的占地/阴影模板，后续正式接入时应按最终像素图复核碰撞与遮挡。
