# 云朵家具套装 v1

用于预览，不自动写入家具库、不更改固件或正在修改的单件组合绘制代码。

- `assets/`：游戏显示尺寸的透明 PNG，尺寸以 manifest.json 为准。
- `masters/`：image-gen 生成的高分辨率母图，仅归档，不应直接打包。
- `assets-preview.png`：全部素材以 1:1 像素展示。
- `room-day-preview.png`、`room-night-preview.png`：使用项目房间合成器制作的搭配示意。
  夜间预览仅切换窗户素材，不包含设备运行时的整屋夜间光照。
- `prompts.json`：内置 image-gen 的完整生成提示词。

床和地毯沿用已认可的云朵详细原款；食盆、墙架、白天窗户、夜间窗户由
内置 image-gen 新生成，再机械导出为实际游戏像素尺寸。
食盆为空碗，方便运行时独立叠加食物。

微雪物理像素：床 160×102、地毯 204×100、食盆 40×28、墙架 112×68、
昼夜窗户各 90×98。对应房间逻辑像素为这些尺寸的一半。

本批仅完成素材与静态预览，未接入或刷入设备。
